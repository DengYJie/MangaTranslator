# MangaTranslator 用户手册 (User Guide)

欢迎使用 MangaTranslator！本手册将帮助您快速了解并掌握 MangaTranslator 的核心功能与完整漫画翻译工作流。

## 1. 快速入门 (Quick Start)

### 1.1 创建与导入项目
在主界面（Home），您可以新建一个项目，或导入已有的漫画文件：
- **支持的导入格式**：本地单图或多图文件夹。
- 导入时，系统会自动提取漫画图像并创建 `project.json` 项目文件，您的所有编辑都会实时、原子化地保存在项目中。

### 1.2 界面概览
- **主界面 (Home)**：管理最近的项目、新建/导入项目。
- **编辑器 (Editor)**：核心工作区，您可以在此对单页漫画进行选区、OCR、翻译、修补与排版操作。
- **设置 (Settings)**：配置 AI 翻译 API（如 OpenAI、DeepSeek）、模型路径等。点击标题栏左侧的“返回”箭头即可随时退出设置。

---

## 2. 核心工作流 (Core Workflow)

MangaTranslator 推荐的单页处理工作流为：**检测 -> OCR -> 翻译 -> 修补 -> 排版**。
您可以在编辑器中分布执行，或在顶部标题栏的「处理」菜单中进行一键处理。

### 2.1 文本检测与选区 (Detection & Regions)
系统内置 ONNX 文本检测模型，可自动识别页面中的文字气泡并生成选区。
- **自动检测**：点击工具栏的「文本检测 (整页)」，系统将自动框选识别到的文字气泡。
- **手动调整**：
  - **矩形选区**：拖拽八向控制点调整大小，另有旋转句柄；方向键微移选区，按住 `Shift` 加大步长。
  - **气泡轮廓**：检测给出的异形气泡多边形轮廓随选区一并显示，用于贴合气泡边缘（暂不支持逐顶点编辑）。
  - **常用按键**：`Delete` 删除选区，`Esc` 取消当前手势，按住 `Space` 临时平移，`+` / `-` 缩放视图，`1` 回到实际大小。

### 2.2 文字识别 (OCR)
将框选的日文/英文等源文本提取为机器可读的字符。
- 点击「文字识别 (整页)」按钮，系统会调用本地配置的 ONNX 模型对选区进行文字识别。日文固定走 Baberu 漫画 OCR，其余语言在 PaddleOCR-VL 可用时优先使用它。
- 识别结果将展示在候选框中，您可以手动修正错漏字后点击采纳。

### 2.3 AI 翻译 (Translation)
利用大语言模型（LLM）将源文本翻译为目标语言。
- **配置 API**：首次使用前，请进入「设置 -> AI 翻译」，填写服务商、API 端点与模型名称，并保存 API 密钥（密钥存入操作系统凭据库，不写进项目文件）。任何提供 OpenAI ChatCompletions 兼容接口的服务都能用，例如 OpenAI、DeepSeek，或本机的 Ollama。
- **执行翻译**：点击「AI 翻译」按钮，系统会发起异步网络请求。我们内置了指数退避与防限流（429）机制，保证批量翻译时的稳定性。
- **结果采纳**：翻译结果将精确对应到各个气泡选区，您可以对翻译结果进行微调。

### 2.4 图像修补 (Inpainting / Clearing)
擦除原有的源文，填充背景，为新排版腾出空间。
- **自动修补**：使用本地模型对文字区域进行智能擦除与背景重构。
- **手动涂抹**：您也可以使用画笔或橡皮擦工具涂抹，调整笔刷直径、选择落笔颜色，做局部补刀或纯色填充。
- *注：所有修补结果均作为非破坏性的衍生资产保存，您的撤销（Undo）操作不会影响原图。*

### 2.5 自动排版 (Typesetting)
将翻译后的文本美观地填入气泡中。
- **横/竖排支持**：支持竖排（Vertical）与横排（Horizontal）排版。
- **样式调节**：支持自动断行、字号自适应计算、行距与字距微调。
- **特效增强**：您可为文字添加描边（颜色与宽度）、外发光（Glow）、阴影（Shadow），以及调整对齐方式。

## 3. 批量处理 (Batch Processing)

对于整话或整本漫画，手动逐页操作效率较低。MangaTranslator 提供了轻量且强大的批处理功能。

- **启动入口**：无需跳转独立页面，直接点击顶部标题栏的「处理 -> 处理项目」。
- **处理流程**：您可以勾选需要的处理阶段（如仅执行 检测 + OCR + 翻译），范围可选全部页面、当前选中页、未处理页或仅失败页。系统按页串行执行。
- **流式内存管理**：批处理会逐页加载、处理并释放页面图像与衍生大图，每页完成后原子提交至项目。已提交的页面已经落盘，中途崩溃不会丢回前面几页。
- **后台任务条**：处理进度、错误提示（如断网）会实时显示在界面底部的状态任务条上，任务条提供「取消任务」。

---

## 4. 数据保存与恢复 (Data & Backup)

- **自动保存**：应用所有的修改与操作均接入全局 Undo/Redo 栈，并自动进行原子化的增量保存：先写入项目同目录的暂存文件，校验通过后原子替换 `project.json`。
- **崩溃恢复**：每次成功保存都会留下一份单代备份 `project.json.bak`。下次打开项目时，如果 `project.json` 本身校验失败，程序自动读回这份备份，并提示数据已恢复自备份，无需您手动选择。导入中途未完成时，项目里会留一个未确认批次标记，打开项目时据此回收已落盘的原图。

---

## 5. 项目导出 (Exporting)

当所有页面编辑与审核完毕后，您可以将项目导出：
- 在「文件」菜单选择「导出...」。
- 支持导出为 PNG 与 JPEG。排版与清理结果复用的是画布同一套测量与光栅化核心，因此导出图与画布预览按同一规则生成；JPEG 会先把透明层压平到白色 sRGB 底色上，质量参数可调。
