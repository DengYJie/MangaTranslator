# MangaTranslator 功能状态与规划清单 (Feature Status & Backlog)

本文档记录 MangaTranslator 当前的已实现功能表、核心工作流架构以及待改善/待开发功能表。

---

## 1. 已实现功能表 (Implemented Features)

| 模块类别 | 功能项 | 说明与技术实现 | 状态 |
| :--- | :--- | :--- | :---: |
| **工程与生命周期** | 项目创建与导入 | 支持从 CBZ 压缩包 (计划中)、本地单图/多图文件夹导入漫画页面，自动提取元数据与原始图像资产 | 已完成 |
| | 原子持久化 | project.json 事务性原子写入与覆盖，崩溃时自动维护 .bak 备份，支持数据自动恢复与提示 | 已完成 |
| | Save As 与项目切换 | 支持另存为独立完整项目，会话切换自动销毁旧任务令牌（Stop Token）并失效旧 Session Generation | 已完成 |
| | 全局撤销/重做 (Undo/Redo) | 单页编辑与全局操作接入 MVVM Undo/Redo 栈，采纳 OCR/翻译/修补均为单次原子提交，支持完整撤销 | 已完成 |
| **文本检测与选区** | ONNX 文本检测 | 接入 Comic Text Detector (ONNX DBNet/YOLO/CTD) 模型，自动识别文字气泡与排版方向 | 已完成 |
| | 任意多边形气泡 | 支持任意凸/凹多边形轮廓顶点调整、增删顶点、拖拽微调及平滑拟合 | 已完成 |
| | 矩形/旋转选区 | 带有中心旋转句柄、八向缩放控制点、微调步进及快捷键（如 Shift 等比/水平垂直吸附） | 已完成 |
| | 手动创建与编辑选区 | 画布工具栏支持自由绘制、快速框选、分割与合并文字气泡 | 已完成 |
| **OCR 文字识别** | 多模型 ONNX 支持 | 支持 Baberu ONNX 与 PaddleOCR-VL-1.6 ONNX 架构，具备模型清单校验（manifest.json）与 SHA-256 完整性检查 | 已完成 |
| | 分词器与文本生成 | 包含 BPE/SPM 分词器、Greedy 贪心搜索生成、重复惩罚与截断保护 | 已完成 |
| | 候选词与交互采纳 | 识别结果生成 Proposal 候选，支持人工微调后一键采纳写入领域模型 | 已完成 |
| **AI 翻译** | 通用 API 接入 | 兼容 OpenAI / Claude / DeepSeek 等标准 ChatCompletions 接口规范 | 已完成 |
| | 异步工作流与网络韧性 | 独立专用网络工作线程、指数退避重试（RetryPolicy）、429 限流等待、401 凭据失效平滑提示 | 已完成 |
| | 候选词与结构化对齐 | 结构化返回多气泡 RegionId 对应译文，严格防止无效 ID 污染领域数据 | 已完成 |
| **图像修补 (Inpainting)** | 笔刷与纯色涂抹 | 支持透明度/粗细可调的交互式橡皮擦涂抹与纯色取色填充修补 | 已完成 |
| | 衍生资产管理 | 擦除与修补结果作为非破坏性不可变衍生资产（assets/derived）存储，Undo/Redo 不触发多余磁盘 I/O | 已完成 |
| **排版与渲染** | 自动文字排版 | QtTextLayouter 支持竖排 (Vertical) 与横排 (Horizontal) 自动断行、字号自适应计算、字距/行距微调 | 已完成 |
| | 字体样式与特效 | 支持描边颜色与宽度、外发光 (Glow)、阴影 (Shadow)、文字加粗与对齐（居中/左/右） | 已完成 |
| | 确定性光栅化 | manga_rendering 模块提供无 Widget 依赖的纯粹渲染管道，保证画布预览与最终导出 100% 像素一致 | 已完成 |
| **批量工作流 (Batch Workflow)** | 全项目多页批处理 | 支持全项目/多页跨页全阶段串行批量处理（检测 -> OCR -> 翻译 -> 修补 -> 排版） | 已完成 |
| | 流式内存与原子提交 | 逐页加载、处理、释放原始与衍生大图显存/内存，每页处理完毕后原子提交至项目，崩溃不丢失已完成页面 | 已完成 |
| | 菜单栏轻量集成 | 无需复杂独立的批量配置页面，直接集成于标题栏「处理」菜单（处理项目/运行检测/OCR/翻译/修补），简单高效 | 已完成 |
| **导出** | 高质量图像导出 | 支持导出为 PNG、JPEG 等常见漫画图片格式，保留高精度排版与修补图层合并 | 已完成 |
| **UI 与交互体验** | 现代化 Fluent 设计 | 完整的 Fluent 控件库与 WinUI 3 视觉语言，支持 Mica / Acrylic 材质背景与 Light/Dark 主题无缝热切换 | 已完成 |
| | 集成标题栏菜单栏 | 标题栏应用名右侧集成 Fluent 风格「文件」与「处理」菜单，与 Windows 11 原生 Hit-Test 完美协同 | 已完成 |
| | 多 Surface 导航与快速返回 | 主界面（Home/Editor/Import）与设置界面（Settings）双 Surface 架构，进入设置时标题栏显示返回按钮，一键快速退回主界面 | 已完成 |
| | 底部状态任务条 | AppStatusTaskStrip 实时展示全局与后台任务进度、取消操作、错误提示与重试入口 | 已完成 |

## 2. 待改善与规划功能表 (Features to Improve & Backlog)

| 优先级 | 模块 | 改进项 | 详细描述与建议方案 |
| :---: | :--- | :--- | :--- |
| **P1** | **翻译增强** | 术语表 (Glossary) 与 Prompt 注入 | 在翻译 UseCase 中增加术语表上下文提取，将角色名、专有名词与上下文剧情统一注入 LLM System/User Prompt |
| **P2** | **导出能力** | 多图层 PSD 格式导出 | 支持将原始背景层、修补层、文字排版层分层导出为 Photoshop PSD 格式，方便汉化组二次精修 |
| **P2** | **导出能力** | 多格式导出 (计划中) | 后续计划支持打包导出，保持高质量色彩配置与元数据 |
| **P2** | **排版增强** | 拟声词 (SFX) 与变形排版 | 支持弧形文字排版、气泡变形字、斜体旋转及更多漫画特效排版样式 |
| **P3** | **硬件加速** | DirectML / CUDA 动态配置 | 在设置页面提供 ONNX Runtime 执行提供商（CPU / DirectML / CUDA）的切换与显存上限调节 |
| **P3** | **用户交互** | 自定义快捷键与手势 | 支持快捷键自定义配置页面、手写板压感支持及触控板平移缩放手势优化 |
