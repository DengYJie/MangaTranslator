# 首页 / 项目中心 UI 设计

## 1. 页面目标

首页让用户在 5 秒内完成以下判断之一：继续最近项目、打开已有项目、导入漫画或创建新项目。它不是数据仪表盘，不展示与下一步无关的统计。

WinUI 3 参考控件：`GridView`、`ListView`、`Button`、`MenuFlyout`、`ProgressBar`、`InfoBar`、`ProgressRing`、`ToolTip`。

页面特有内容使用现有控件组合，不新增自定义控件。

## 2. 页面结构

从上到下：

1. Page Header。
2. 可选的全宽 `InfoBar`。
3. 最近项目区域。
4. 快速开始与最近活动辅助区域。

### 2.1 Page Header

左侧：

- H1：`欢迎回来` 或首次使用时 `开始使用 MangaTranslator`。
- 一行说明：`继续漫画翻译项目，或开始新的工作。`

右侧命令：

- 次要按钮 `打开项目`。
- 主按钮 `新建项目/导入`。

“新建项目”和“直接导入”使用同一个入口。进入后依次选择来源、项目保存位置、语言和引擎，不在首页拆成两套流程。

### 2.2 最近项目

使用 `GridView` 行为参考：同质卡片、单选、键盘方向键移动、Enter 打开。

每张项目卡包含：

- 16:10 或接近漫画页比例的封面缩略图。
- 项目名称。
- 页数。
- 最近打开时间。
- 处理完成比例和 `ProgressBar`。
- 可恢复异常标记，例如源文件移动、模型缺失、上次异常退出。

卡片正文不可依赖封面文字。缩略图加载失败时显示中性占位和文件类型图标。

卡片右键 `MenuFlyout`：

- 打开。
- 在文件夹中显示。
- 从最近列表移除。
- 修复源文件位置，仅在路径失效时显示。
- 删除项目文件；危险项置于分隔符之后，并打开 `ContentDialog`。

### 2.3 快速开始

使用普通 `Button` 或图标 + 文本的方形按钮，不使用导航项样式：

- 从图片创建项目。
- 从图片文件夹创建项目。
- 恢复中断任务；仅存在可恢复任务时显示。

每个动作同时显示图标和文字。按钮的整个 Surface 可点击；图标不单独成为 Tab Stop。

### 2.4 最近活动

使用紧凑 `ListView` 行为参考。每行包含状态图标、动作摘要、项目名和相对时间。活动只记录安全元数据，不显示完整漫画文本或密钥。

点击活动行：

- 项目仍存在：进入对应项目和页面。
- 项目不可用：显示内联 `InfoBar`，提供定位或从列表移除。

## 3. 布局

### 3.1 Wide `>=1440`

- 页面最大内容宽度可限制为约 1600 px，水平居中。
- 最近项目占约 70%，辅助区域占约 30%。
- 项目卡 3–4 列；卡片最小宽度 220 px。
- Page Header 与内容间距 24 px，项目卡间距 16 px。

### 3.2 Standard `1200–1439`

- 仍为主/辅两栏。
- 项目卡 3 列。
- 辅助栏 300–340 px。

### 3.3 Compact `1008–1199`

- 项目卡 2 列。
- 快速开始移到最近项目下方，最近活动再下移，形成单列页面流。
- Page Header 按钮保持同一行；空间不足时文字说明先缩短。

### 3.4 Narrow `720–1007`

- 单列滚动页面。
- Page Header 命令可换行到标题下方，主按钮排在前。
- 快速开始按钮两列；项目卡一至两列，取决于卡片最小宽度。

### 3.5 Minimum `<720`

- 项目卡单列。
- Header 操作占满可用宽度；主按钮在上或右侧，不使用仅图标表示“新建”。
- 最近活动最多显示 5 条，余下通过 `查看全部` 进入独立列表。

## 4. 交互与动效

### 4.1 打开项目

1. 用户激活卡片。
2. 卡片保持选中，卡片内部显示小型 `ProgressRing` 和 `正在打开`。
3. 其他卡片仍可浏览，但重复打开动作禁用。
4. 成功后进入编辑器；可使用轻量 Connected Animation 思想，让封面位置与页面缩略图产生连续感，但首版可仅做页面淡入。
5. 失败时保留首页，卡片恢复可操作，并在页面顶部显示 `InfoBar`。

### 4.2 Hover 和选择

- Hover：卡片背景提升一级，缩略图轻微增亮；不做超过 1.01 的缩放。
- Pressed：Surface 下压感由背景和描边变化表达，不移动文字。
- Selected：焦点框与选中描边分离；键盘焦点不等于已打开。
- Loading：卡片内容不整体降低透明度，以免用户无法识别正在打开哪个项目。

## 5. 页面状态

### 5.1 首次使用 / Empty

不显示空的最近项目网格。中央显示：

- 插图或简洁文件图标。
- H2：`创建第一个漫画项目`。
- 一句说明。
- 主按钮 `新建项目/导入`，次要按钮 `打开已有项目`。

快速开始可以保留，但避免与空状态重复四组主按钮。

### 5.2 Loading

- 读取最近项目通常很短，超过 300 ms 才显示局部 `ProgressRing`。
- 不使用全窗模态等待。
- 缩略图逐项异步出现；出现时 100–150 ms 淡入，位置不可重排。

### 5.3 Partial

可用卡片正常显示；异常卡片显示明确状态：

- `源文件已移动`。
- `项目格式需要升级`。
- `上次任务未完成`。
- `所需模型未安装`。

异常不让整个首页进入 Error 状态。

### 5.4 Error

最近列表加载失败：页面顶部 `InfoBar` 显示原因和 `重试`。`新建项目/导入` 与 `打开项目` 仍可用。

## 6. 键盘和无障碍

- Page Header 操作按视觉顺序进入 Tab。
- GridView 内方向键移动，Enter 打开，Shift+F10 打开上下文菜单。
- 卡片无障碍名称包含项目名、页数、进度和异常状态。
- ProgressBar 的可访问值为 `20/28 页，71%`，不能只播报百分比。
- 相对时间提供完整日期作为说明或 ToolTip。
- 空状态图像为装饰，不进入无障碍树。

## 7. 验收场景

- 0、1、3、20 个最近项目时布局稳定。
- 缩略图加载慢或失败时卡片不跳动。
- 名称为 40 个中日韩字符或长英文路径时不挤压按钮。
- 断网时本地项目仍可打开。
- 200% 文本缩放时页面可以滚动且主操作不丢失。
- 键盘可完成打开项目、打开上下文菜单和移除记录。
