# 批量翻译 UI 设计

## 1. 页面目标

批量翻译页用于配置和观察整章流水线。它必须让用户快速回答：任务是否仍在运行、当前处理哪一页、哪里失败、能否安全离开、下一步该做什么。

WinUI 3 参考控件：`CommandBar`、`Button`、`SplitButton`、`ComboBox`、`NumberBox`、`ToggleSwitch`、`ProgressBar`、`ProgressRing`、`InfoBar`、`InfoBadge`、`ListView`、`MenuFlyout`、`ContentDialog`、`ToolTip`。

自定义控件：

- [TaskStageGrid](../components/task-stage-grid.md)
- [AppStatusTaskStrip](../components/status-task-strip.md)

## 2. 页面模式

页面有两个主要模式：

1. `configuration`：尚未开始，展示页面范围与流水线配置。
2. `monitoring`：任务已排队、运行、暂停、完成、失败或取消，展示摘要与阶段矩阵。

两种模式属于同一页面，不是两个独立一级页面。任务运行后仍可查看只读配置摘要。

## 3. Configuration 模式

### 3.1 Header

- H1：`批量翻译`。
- 说明：`处理整章页面，并集中检查失败项。`
- 主按钮：`开始处理`。

### 3.2 页面范围

- 全部页面、未处理页面、选中范围、需要重试页面。
- 2–4 个常用选项使用 `RadioButtons`；自定义范围出现 `NumberBox` 起止输入。
- 显示解析结果：`将处理 28 页，跳过 3 个已校对页面`。
- 范围为空时立即显示字段级错误，主按钮禁用。

### 3.3 流水线阶段

顺序固定为：检测 → OCR → 翻译 → 清除 → 排版 → 可选导出。

每阶段一行：

- `ToggleSwitch` 启用/停用。
- 引擎或模型 `ComboBox`。
- 依赖摘要。
- 可选高级设置 `Button` 打开 `Flyout`。

依赖规则：

- 启用 OCR 时必须存在 Region；若关闭检测，则说明将使用已有 Region。
- 启用翻译时必须存在 OCR 文本；允许选择 `仅翻译已有 OCR`。
- 清除和排版可独立于翻译重新运行，但需说明使用哪个文本版本。
- 自动导出默认关闭；开启后显示目标路径和覆盖策略。

### 3.4 资源与费用摘要

在主按钮附近显示：

- 预计页面数。
- 使用的本地模型与远程 Provider。
- 远程发送内容范围。
- 并发度或性能档位。
- 若可估算，显示费用范围；不可估算时说明计费取决于文本量。

首次发送漫画文本到远程 Provider 时，使用 `ContentDialog` 明确隐私范围。已在设置中确认且 Provider 未变化时不重复打断。

## 4. Monitoring 模式

### 4.1 Header actions

根据任务状态显示：

- Running：`暂停`、`取消任务`。
- Pausing：`正在暂停`，按钮禁用，允许 `取消任务`。
- Paused：主按钮 `继续处理`、次要 `取消任务`。
- CompletedWithIssues：主按钮 `重试失败项`、次要 `进入校对`。
- Completed：主按钮 `进入校对`、次要 `导出`。
- Cancelled：`继续未完成项` 或 `新建任务`。

不要同时显示互相矛盾的暂停和继续按钮。

### 4.2 Summary Card

内容：

- `已完成 18 / 28 页`。
- 总 `ProgressBar`。
- 当前项：`第 19 页 · 正在翻译`。
- 数量摘要：完成、处理中、等待、失败、取消。
- 预计剩余时间仅在稳定样本足够时显示；波动大时省略，不展示虚假精度。

### 4.3 Configuration Summary

只读显示流水线、模型和范围。提供 `查看完整配置` Flyout。运行中不允许修改会改变任务输入的设置；需要修改时先暂停或取消并创建新任务。

### 4.4 TaskStageGrid

每行一页，每列一阶段。详见 [task-stage-grid.md](../components/task-stage-grid.md)。页面级要求：

- 当前运行页自动滚入视图，但只有用户未主动离开当前位置时才跟随。
- 用户滚动查看历史页后显示 `返回当前任务` 浮动按钮，不强行抢回滚动位置。
- 筛选：全部、处理中、失败、需要检查、完成。
- 搜索：页码或文件名，使用 `AutoSuggestBox` 可选。
- 行右键：重试此页、跳过、打开编辑器、查看日志、导出此页。

## 5. 状态语义

页面与阶段状态：

- Pending：空心圆 + `等待`。
- Queued：队列图标 + `已排队`。
- Running：活动指示 + 阶段名，可有局部百分比。
- Paused：暂停图标 + `已暂停`。
- Completed：勾号 + `完成`。
- NeedsReview：Caution 图标 + `需要检查`。
- Failed：Critical 图标 + `失败`。
- Cancelled：停止图标 + `已取消`。
- Skipped：短横线 + `已跳过`。

颜色不得是唯一编码。完成与人工校对完成必须区分：流水线完成使用 `完成`，人工确认使用 `已校对`。

## 6. 暂停、继续和取消

### 6.1 暂停

- 点击后状态立即变为 Pausing。
- 不再启动新页面；正在运行阶段在安全检查点暂停或完成当前原子步骤。
- 所有正在运行的阶段到达安全暂停点后进入 Paused。
- 如果某阶段暂不可暂停，说明 `等待当前 OCR 推理完成`。

### 6.2 继续

- 从可恢复检查点继续。
- 已完成阶段不重复运行，除非任务输入已变化。
- 若 Provider/模型在暂停期间不可用，显示 `InfoBar` 并阻止继续，提供打开设置。

### 6.3 取消

- `取消任务` 打开 `ContentDialog`，说明已完成结果会保留、未开始项将取消。
- 确认按钮文字为 `取消剩余任务`，安全按钮为 `继续处理`。
- 取消进入 Cancelling，直到所有工作停止或脱离回调。
- 任务取消后不删除已保存页面结果。

## 7. 错误和重试

- 单页失败不弹全局 Dialog；行进入 Failed，总摘要计数增加。
- 认证/配额/网络全局失败导致大量页面必然失败时，任务自动暂停，页面顶部显示 Critical `InfoBar`。
- `重试失败项` 创建新的请求代次，只包含失败页及其失败阶段依赖。
- 重试前若人工修改了页面，显示冲突摘要并默认保留人工修改。
- `查看日志` 只展示安全诊断，不显示完整密钥或默认记录漫画全文。

## 8. 离开页面

任务运行时允许导航到编辑器、术语库或设置。

- `AppStatusTaskStrip` 持续显示任务状态、简要进度和返回批处理页入口。
- 离开页面不停止任务。
- 关闭项目或应用时，根据任务可恢复能力显示 `ContentDialog`：等待安全停止、取消并退出、返回应用。
- 任务完成后可用非侵入式通知提示，但不自动抢焦点或切换页面。

## 9. 响应式布局

### 9.1 `>=1200`

- Summary 与 Configuration Summary 两栏。
- TaskStageGrid 占剩余高度。

### 9.2 `1008–1199`

- 摘要两栏保持，但右侧配置缩窄。
- 阶段列使用紧凑标签或图标 + ToolTip；状态仍有可访问文本。

### 9.3 `720–1007`

- 摘要和配置纵向堆叠。
- TaskStageGrid 切为每页卡片式阶段条，避免水平表格被压扁。
- 筛选与操作进入 CommandBar Overflow。

### 9.4 `<720`

- 只显示总进度、当前页和失败数摘要。
- 每页行按需展开阶段详情；默认一次只展开一页。
- 主按钮保持文字，不使用孤立播放/暂停图标。

## 10. 键盘和无障碍

- TaskStageGrid 行使用上下键；左右键在阶段单元格间移动。
- Enter 打开页面详情；Shift+F10 打开行菜单。
- 进度更新以关键里程碑播报，不逐百分比轰炸。
- 状态单元格可访问名称包含页、阶段、状态和错误摘要。
- 暂停、继续、取消按钮的可用状态必须与当前任务状态一致。
- 聚焦某失败行时刷新其他行不得丢失焦点。

## 11. 验收场景

- 1、28、500 页任务。
- 全成功、部分失败、全局认证失败、暂停中断、应用重启恢复。
- 运行中离开并返回页面。
- 用户查看历史行时当前页继续变化，滚动不被强制拉回。
- 重试期间人工修改页面，旧结果不覆盖。
- 窄宽度卡片模式、高对比度和仅键盘操作。
