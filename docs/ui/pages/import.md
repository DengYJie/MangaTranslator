# 新建项目 / 导入 UI 设计

## 1. 页面目标

导入页把多来源文件统一转换为 `ComicProject -> ComicPage[]`。用户应清楚知道导入什么、保存到哪里、将采用哪些默认处理设置，以及哪些文件不能导入。

WinUI 3 参考控件：`Button`、`ListView`、`ProgressBar`、`ProgressRing`、`TextBox`、`ComboBox`、`RadioButtons`、`ToggleSwitch`、`InfoBar`、`ContentDialog`、`Flyout`、`ToolTip`。

文件 Drop Zone 是页面内自定义交互 Surface，但不需要形成公共控件 API；若后续多个页面复用，再抽成 `FileDropZone`。

## 2. 流程结构

导入由三个阶段组成：

1. 选择文件。
2. 项目设置。
3. 检查并导入。

阶段指示器是只读进度，不允许用户跳过未满足验证的步骤。当前首版可在单页上同时展示文件区和设置区，但内容与文案仍按三阶段组织。

不要使用 `TabView` 表示阶段，因为这些不是可任意切换或管理的文档。阶段标签可以使用普通布局与状态图标。

## 3. 页面解剖

### 3.1 Header

- H1：`导入漫画`。
- 说明：支持的来源与导入结果。
- 无全局主按钮；提交按钮位于设置面板底部，靠近决策数据。

### 3.2 Source Pane

包含阶段指示器、Drop Zone、文件列表和来源错误。

Drop Zone 内容：

- 导入图标。
- 主句：`拖放漫画文件或文件夹到这里`。
- V0.1 支持格式说明：`JPG、JPEG、PNG、WEBP、图片文件夹`。CBZ/ZIP 与 PDF 从 V0.2 开始显示。
- 按钮：`浏览文件`。
- 可选次要按钮：`选择文件夹`。

视觉状态：

- Rest：中性 Surface + 1 px 虚线边界。
- Drag Enter：Accent 低透明度背景，边界变实或加亮，文字改为 `释放以添加`。
- Rejected Drag：Critical 边界，文字说明具体不支持的类型；离开后恢复。
- Disabled：导入提交期间禁止继续添加，显示 `导入进行中`。

拖放命中区域覆盖整个 Drop Zone；内部图标和文字不拦截 Drop 事件。

### 3.3 Pending File List

参考 `ListView`。每个顶级来源一行：

- 类型图标或首张缩略图。
- 文件/文件夹名。
- 检测到的页面数与大小。
- 状态：正在扫描、可导入、有警告、失败。
- 行末移除按钮；Hover 或焦点时显示。

展开来源内部文件不是首版默认行为。若扫描发现问题，行下方展示最多 2 条摘要，并提供 `查看详情` 打开 `Flyout` 或独立问题列表。

文件顺序：

- 默认自然排序。
- 用户可以拖动重排顶级来源。
- 单页顺序调整在导入前预览或编辑器页面列表中完成，不在来源列表同时提供两套重排。

### 3.4 Project Settings Pane

字段：

- 项目名称：`TextBox`。
- 保存位置：只读 `TextBox` + `浏览` Button。
- 阅读方向：两项 `RadioButtons` 或水平互斥 Toggle；语义为从左到右、从右到左。
- 源语言：`ComboBox`。
- 目标语言：`ComboBox`。
- OCR 引擎：`ComboBox`。
- 翻译 Provider/模型：一个或两个 `ComboBox`，取决于 Provider 是否决定模型列表。
- 使用术语库：完整术语工作流可用后显示。
- 使用页面上下文：支持相应翻译范围的版本中显示。

字段使用显式标签，不只靠 Placeholder。所有自动推断值旁显示 `自动识别` 状态，并允许修改。

底部动作：

- `取消`：返回首页；有未提交来源时不必确认，因为数据尚未写入项目，除非扫描下载了大体积资源。
- 主按钮 `创建并导入`。

主按钮文案按阶段变化：

- 尚未扫描完成：`正在检查文件`，禁用。
- 验证失败：`修正问题后导入`，禁用。
- 可提交：`创建并导入`。
- 进行中：`正在导入 12/28`，禁用重复点击；旁边出现 `取消导入`。

## 4. 验证行为

验证分为字段级、来源级和提交级。

### 4.1 字段级

- 项目名为空或包含不允许字符：输入下方显示错误，焦点离开不清除用户文本。
- 保存位置不可写或空间不足：显示原因和 `选择其他位置`。
- 源语言等于目标语言：显示 Caution，但允许继续；说明此配置适用于校对、重排和再处理场景。
- Provider 未配置：显示内联帮助和 `打开设置`，进入 Settings Surface 后 Back 返回导入页并保留表单。

### 4.2 来源级

- 不支持格式：对应行 Error，不阻止其他合法来源预览；提交前要求移除或修复。
- 加密/损坏压缩包：从支持归档导入的版本开始，行 Error 并提供 `查看诊断`。
- PDF 页面渲染失败：从支持 PDF 的版本开始显示失败页数和可继续策略；不能静默少页。
- 重复文件：Caution，提供 `保留一个`。
- 超大图片或压缩包风险：阻止导入，说明安全限制。

### 4.3 提交级

点击提交后聚焦第一个错误；页面顶部 `InfoBar` 汇总：`有 3 项需要修正`。InfoBar 不替代字段下方具体错误。

## 5. 异步与进度

扫描阶段：

- 每个来源行有独立 `ProgressRing`。
- 页面总计仍在更新时显示 `正在扫描…`，不要显示错误的 0 页。
- 扫描结果按请求代次合并；用户移除来源后，旧结果不得把它重新加回列表。

导入阶段：

- 显示总体 `ProgressBar`、当前文件和 `已完成/总页数`。
- 可取消；取消后删除未提交的临时项目，保留用户表单以便重试。
- 页面导入失败时默认不中断其他页面，完成后进入 `partial` 状态，让用户决定跳过失败页或修复重试。
- 成功后进入编辑器，并将第一页作为当前页；如果零页成功则不得创建空项目并宣称成功。

## 6. 响应式布局

### 6.1 `>=1200`

- Source Pane 与 Settings Pane 两栏。
- Source Pane `minmax(0, 1fr)`；Settings Pane 360–420 px。
- Settings Pane 可内部滚动，但提交按钮固定在面板底部。

### 6.2 `1008–1199`

- 两栏保留，Settings Pane 340–380 px。
- 支持格式说明缩短；不缩小输入框高度。

### 6.3 `720–1007`

- 切为单列：文件区在上、项目设置在下。
- 页面整体滚动；提交动作在设置末尾，不做遮挡内容的浮动按钮。
- 阶段指示器缩短连接线但保留三个阶段名称。

### 6.4 `<720`

- 阶段指示器只显示当前阶段和 `1/3`，其余通过简短摘要表达。
- Drop Zone 高度缩小但命中区不小于 160 px。
- 两个底部按钮垂直或等宽排列。

## 7. 动效

- Drag Enter 背景和描边 100 ms 过渡；不使用持续脉冲。
- 新来源行 160 ms 淡入并从 8 px 下方进入；批量添加时按 20 ms 轻微错开，上限 6 项，避免长动画。
- 删除行先立即从交互模型移除，再做 120 ms 收起；Undo 如需支持，以 Toast 提供短时间恢复。
- 阶段完成图标 200 ms 从进度环过渡到勾号，颜色变化同时有形状变化。

## 8. 键盘与无障碍

- `Ctrl+O` 打开文件选择器；页面内另提供选择文件夹按钮。
- 文件列表支持方向键、Delete 移除、Ctrl+A 全选；Delete 前不对可恢复的“从待导入列表移除”弹确认。
- Drop Zone 的可访问名称说明支持来源和当前状态。
- 阅读方向的选项被完整朗读，不只播报图标。
- 扫描和导入进度以节流方式发送可访问通知，避免每个百分比都打断屏幕阅读器。
- 错误摘要可导航到具体错误字段或来源行。

## 9. 验收场景

- V0.1 覆盖单张图片、500 张图片、图片文件夹和混合图片来源；V0.2 增加 CBZ/ZIP、PDF 及混合归档来源。
- Unicode、Emoji、超长路径和自然排序。
- 扫描中移除来源、再次添加同一来源、取消后重试。
- Provider 未配置时往返设置页面，表单不丢失。
- 磁盘空间不足、权限不足、部分页面失败和零页成功。
- 720/1008/1200 px 边界、200% 文本缩放和高对比度。
