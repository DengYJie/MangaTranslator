# TaskStageGrid 自定义控件设计

## 1. 控件定位

`TaskStageGrid` 显示“页面 × 流水线阶段”的状态矩阵。WinUI 3 本体没有可直接引用的第一方 DataGrid，因此本控件独立定义列布局、焦点、选择、大数据量浏览和无障碍行为。

## 2. 显示内容

每行：一个稳定 Page ID。

固定阶段列：

- Detection。
- OCR。
- Translation。
- Cleaning。
- Typesetting。
- Export，可选。

每单元格数据：

- Stage ID。
- Status。
- Progress，可选。
- Started/Finished time，可选。
- Error category + safe summary，可选。
- Retryable。
- 结果所属的页面与任务运行标识；迟到的旧任务结果不得替换新任务状态。

## 3. 表格解剖

### Header

- 页面列标题。
- 文件名列标题。
- 阶段列标题。
- 总状态列标题。

Header 保持可见；纵向滚动时 Sticky。表格无法在当前宽度下完整呈现关键列时切换为卡片模式，避免依赖复杂的双向冻结与横向滚动。

### Row

- 页面缩略图/页码。
- 文件名。
- 每阶段状态单元格。
- 总状态 Badge/文字。

行高 52–60 px。任何状态更新不改变行高。

## 4. 单元格状态

| 状态 | 图标 | 文字 | 可操作 |
| --- | --- | --- | --- |
| Pending | 空心圆 | 等待 | 可跳过 |
| Queued | 队列 | 已排队 | 可移出队列 |
| Running | 活动指示 | 进行中/百分比 | 可查看、任务级取消 |
| Paused | 暂停 | 已暂停 | 可继续 |
| Completed | 勾号 | 完成 | 可重新运行 |
| NeedsReview | 警告 | 需检查 | 打开编辑器 |
| Failed | 错误 | 失败 | 重试、查看详情 |
| Cancelled | 停止 | 已取消 | 重试 |
| Skipped | 短横线 | 已跳过 | 恢复 |
| NotApplicable | 空白/短横线 | 不适用 | 无 |

图标与文字可在标准模式同时显示；紧凑模式只显示图标，但可访问名称和 ToolTip 必须包含文字。

## 5. 行总状态推导

优先级：

```text
Failed > NeedsReview > Running > Paused > Queued > Pending > Completed > Skipped
```

但总状态不覆盖单元格事实。例如 OCR 失败导致后续阶段 Skipped，行总状态为 Failed。

## 6. 交互

- 单击行选择页面。
- 双击或 Enter 打开编辑器对应页面。
- 单击失败单元格打开详情 Flyout：安全错误摘要、发生时间、重试此阶段、打开日志。
- 右键行打开 `MenuFlyout`：重试此页、跳过、打开编辑器、导出、查看日志。
- 点击列标题只在支持排序时响应；默认阶段列不可重排。

Running 单元格不放独立取消按钮，避免每格噪声；取消在行菜单或任务级操作中提供。

## 7. 进度动画

- Running 图标使用有限、平滑活动动画；减少动画时用静态活动图标 + 文字。
- 单元格从 Running → Completed：200–260 ms Cross-fade 为勾号。
- Running → Failed：立即切换 Critical 图标，80–120 ms 颜色过渡，不抖动。
- 数字进度刷新节流到 100 ms；小于 1% 的变化可不刷新文字。
- 列宽和行高在动画中保持不变。

## 8. 当前任务跟随

- 当前运行行使用细 Accent 左边指示器，不覆盖 Selected 背板。
- 用户未主动滚动时，当前行变更可平滑滚入视图。
- 用户在最近 2 秒内滚动或焦点位于其他行时停止自动跟随。
- 停止跟随后显示 `返回当前任务` Button；激活后恢复跟随。

## 9. 筛选、排序与批量选择

- 筛选：全部、进行中、失败、需要检查、完成。
- 默认排序为项目页面顺序。
- 可选按状态、最近更新排序，但切回页面顺序入口清晰。
- 多选用于 `重试所选`、`跳过所选`、`打开所选中的第一项`。
- 筛选更新不清空仍存在的选择；隐藏选择数在 Toolbar 显示。

## 10. 响应式

### Table mode `>=1008`

- 所有主要阶段为列。
- 空间不足时文件名缩短，阶段单元格先隐藏文字保留图标。
- 不通过水平滚动隐藏页码和总状态；若无法容纳，切卡片模式。

### Card mode `<1008`

每页一张紧凑卡：

- 顶部：页码、文件名、总状态。
- 中部：阶段按水平步骤条或两列网格。
- 默认显示当前/失败阶段；激活后展开完整阶段。
- 一次可展开多项，但应虚拟化。

## 11. 错误详情 Flyout

内容：

- `第 20 页 · OCR 失败`。
- 一句用户可理解原因。
- 安全诊断码。
- 按钮 `重试 OCR`、`在编辑器中打开`。
- 链接 `查看日志`。

不显示堆栈、密钥、完整请求或漫画全文。若错误会影响所有页面，使用页面级 InfoBar，而不是每格重复 Flyout。

## 12. 键盘与无障碍

- Tab 进入 Grid 后，上下键换行，左右键换阶段单元格。
- Home/End 到行首尾；Ctrl+Home/End 到表首尾。
- Enter 打开详情或页面；Space 选择行；Shift+F10 菜单。
- 每单元格播报 `第 20 页，OCR，失败，模型输出格式无效，可重试`。
- 更新当前未聚焦单元格不自动打断；任务完成/全局失败通过节流通知播报。
- 卡片模式保持相同语义顺序。

## 13. 性能与验收

- 5000 行时必须虚拟化。
- 高频状态更新只更新受影响行/单元格。
- 排序或筛选不丢稳定 Page ID 和焦点。
- 进度更新不改变列宽、行高和滚动位置。
- Table/Card 模式信息一致。
- 仅键盘和屏幕阅读器可定位失败并重试。
