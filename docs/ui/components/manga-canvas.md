# MangaCanvas 自定义控件设计

## 1. 控件定位

`MangaCanvas` 是漫画页面的二维编辑视口。WinUI 3 `ScrollView` 可作为滚动、平移和缩放的交互参考，但它不提供漫画图层、Region 编辑、源图坐标和非破坏性合成，因此本控件独立定义内容、样式、功能和行为。

## 2. 坐标系统

### 2.1 规范坐标

所有持久 Region、Mask、TextLayout 和人工覆盖使用源图像像素坐标。源图左上为 `(0,0)`，X 向右，Y 向下。

必须明确区分：

- Source Image Coordinates：Region、Mask 和排版属性的规范坐标。
- Canvas Coordinates：页面在工作区中的显示位置。
- Viewport Coordinates：指针与可见区域使用的逻辑坐标。
- Export Coordinates：最终输出坐标。

缩放、平移和窗口缩放不能改变 Region、Mask 或排版在源图中的实际位置。

### 2.2 精度

- Region 使用源图像像素坐标和浮点精度。
- Inspector 显示 X/Y/W/H；V0.1 不显示旋转角度。
- 缩放和平移不改变 Region 数据。
- 导出结果不受用户当前画布缩放和平移影响。

## 3. 显示图层

从底到顶：

1. Workspace background。
2. Page shadow。
3. Original Image Layer。
4. Cleaning Layer。
5. Translation / Manual Override Layer。
6. Region Overlay Layer。
7. Selection and Handles Layer。
8. Guides and Reading Order Layer。
9. Tool Preview Layer。
10. Busy/Error Overlay Layer。

实现使用固定 Z 值：Workspace `0`、Original `10`、Cleaning `20`、Text `30`、Region `100`、Handles `110`、Tool Preview `200`。V0.1 没有 Split Curtain，不预留帘布 Item 或裁切分支。

图层显示规则：

- `原图`：只显示 Original；Region 可按设置显示。
- `清理`：Original + Cleaning。
- `翻译`：Original + Cleaning + Translation。
- `对比`：V0.1 并排显示原图与翻译结果，Region 默认只读隐藏。
- Mask 预览可覆盖 Cleaning Layer，使用半透明颜色但不得改变实际 Mask。

任何异步图层更新都不能改变当前缩放、滚动中心、选择或工具，也不能造成整张画布闪白。

## 4. 视口背景与页面

- Manga 文档 workspace 与 viewport 在浅色主题中使用浅色中性背景 `#F3F3F3`，在深色主题中使用中性深色背景 `#202124`；外层 pane 可使用 FluentQt 语义主题色。由画布控件统一绘制视口背景。
- 浅色和深色主题必须使用不同的画布演示稿，不得仅切换外层面板颜色后复用同一张截图。深色演示使用深色 Fluent 外壳、深色工作区、浅色页面和高对比选区；浅色演示使用浅色 Fluent 外壳、浅色工作区、较柔和的页面阴影和在浅色工作区上清晰识别的选区颜色。
- 两套演示稿必须覆盖相同的核心状态：页面、非破坏性图层、Region 选区、翻译文本和缩放控件；页面构图、文字内容或选区状态至少有一项不同，以便评审主题适配而不是只检查换肤。
- `NoProject` 状态在画布中心显示轻量状态卡，包含文件夹图标、标题、说明和打开项目按钮；`Loading`、`NoPage` 与 `Error` 保留各自的状态信息和动作，不使用全屏遮罩。
- 可选 24 source px 细网格只用于空间感；缩放低于 25% 时固定隐藏，减少视觉干扰时也隐藏。
- 页面周围最少 24 px 空间；适应页面时考虑 CommandBar 和 Overlay 安全区。
- 页面阴影为低至中等 Elevation，不能污染页面实际像素。
- 透明页面用棋盘格仅在确有 Alpha 时显示；普通漫画页不显示棋盘格。
- 页面加载失败显示页面边界、错误图标、文件名和 `重试加载`，画布仍可平移缩放。

## 5. 缩放

### 5.1 范围

- 最小 5%，适应整页计算结果更小时仍 Clamp 到 5%。
- 最大 1600%。
- 常用预设：25%、50%、100%、200%、适应页面、适应宽度。
- 缩放值在 CommandBar 可见，格式化为整数百分比；内部保留浮点。

### 5.2 输入

- `Ctrl+滚轮`：以指针位置为锚缩放。
- 触控板 Pinch：以手势中心为锚连续缩放。
- `+/-`：在 5%、10%、25%、50%、75%、100%、150%、200%、400%、800%、1600% 档位间切换，以视口中心或当前选择为锚；当前值位于两档之间时，`+` 取更高一档，`-` 取更低一档。
- CommandBar 预设：使用 180–240 ms 的平滑视图变换；减少动画时即时。
- 双击空白画布：在 100% 与适应页面间切换；若双击被 Region 捕获，则进入 Region 编辑而非缩放。

### 5.3 稳定性

- 缩放后指针下源图位置尽量保持不变。
- 连续手势期间保持平滑预览；手势结束后记住最终 Zoom 和 Center。
- 页面切换时恢复该页上次视图或应用全局偏好。
- 适应页面计算不得包含暂时展开的 ToolTip/Flyout。

## 6. 平移与滚动

- Space+左键拖动：临时平移，松开 Space 恢复原工具。
- 中键拖动：平移。
- 平移工具选中时左键拖动：平移。
- 触控双指：平移；单指行为取决于触摸模式。
- 滚轮：垂直滚动；Shift+滚轮：水平滚动。
- 视口边缘可允许有限 Overscroll 以便编辑页面边缘，但松手后回弹到合理范围。

拖动期间：

- 指针变为抓取/抓取中形态。
- 不显示惯性拖尾。
- Region Hover 暂停，避免大量重绘。
- 释放后在下一帧恢复 Hover 命中测试。

## 7. 工具状态机

互斥工具：

- Select。
- Pan。
- Create Region。

V0.1 只提供以上三种主工具。Edit Polygon、Rotation 和 Read Order 工具属于后续版本。

临时工具：

- Space → Pan。
- Alt 或指定修饰键 → 从中心缩放/调整，具体由 Region 文档定义。

状态机规则：

- 一次只允许一个主工具 Active。
- 切换工具前取消未提交预览；若已有实际数据变化，通过 Undo Command 回滚。
- Escape 只取消当前手势，不改变主工具；再次 Escape 可退出临时模式。
- 页面切换、关闭项目和开始不兼容的异步任务前必须结束或取消手势。

## 8. 选择

- 单击 Region：单选。
- Ctrl+单击：切换多选成员。
- Shift+单击：按阅读顺序选择范围；没有稳定顺序时禁用此语义。
- 拖动空白区域：框选；必须区分从左到右和从右到左是否采用不同包含规则，首版统一为与矩形相交即选中。
- 单击空白：清除选择。
- Tab/Shift+Tab：按阅读顺序移动 Region 选择；画布具有焦点时生效。

内容刷新或阅读顺序变化后，只要 Region 仍存在，就应保持相同的主要选择和多选集合。

## 9. 创建 Region

### 9.1 矩形创建

1. 按下记录源图起点。
2. 拖动显示 Tool Preview，使用 Accent 虚线与半透明填充。
3. 尺寸小于最小阈值时标记为无效。
4. 松开后创建 Region。
5. 成功后新 Region 成为唯一选择并打开 Inspector 翻译区。

如果创建手势将产生越界矩形，预览显示无效状态，松开后不创建。起点在页面外时不开始创建。

### 9.2 后续几何类型

V0.1 不提供多边形创建或旋转。后续版本加入多边形时，需要提供逐点创建、完成、撤回最后一点和取消整次创建的完整行为，且闭合前不得产生正式 Region。

### 9.3 自动能力兜底

创建矩形归一化后宽或高小于 8 source px 时视为无效，不写入 Domain，也不产生 Undo Command。手工创建永远可用；V0.1 不提供自动文字检测。新建 Region 的来源标记为 Manual。

## 10. 编辑 Region

区域绘制、Handle 和状态详见 [region-overlay.md](region-overlay.md)。MangaCanvas 提供：

- 命中测试顺序。
- 指针捕获。
- 坐标转换。
- 手势预览。
- 手势完成确认。
- 清晰的 Undo/Redo 动作边界。

移动和缩放在拖动中只更新轻量预览 Item；松手时提交一次业务变更。若需要实时排版预览，节流到每 16–33 ms，且不得运行完整高成本排版。

## 11. Undo/Redo

可撤销动作：

- 创建、删除、移动和缩放矩形 Region。
- 人工文本与排版属性变更。
- 可逆的清理层选择与 Mask 手工修改。

旋转、多边形顶点和阅读顺序调整在相应后续功能交付时纳入 Undo/Redo。

连续拖动是一个 Undo Command，不按每个 MouseMove 生成命令。文字输入可按焦点会话或时间合并，保持符合编辑器预期。

异步自动结果：

- 被用户明确采用后进入 Undo 栈。
- 自动任务到达但尚未采用的候选不污染 Undo 栈。
- 重新运行阶段前保存可恢复快照或生成可撤销替换命令。
- 清除结果先在后台准备不可变派生资产；GUI 线程收到 `PreparedClearChange` 后再 push 命令，命令的 redo/undo 只同步切换 Domain 引用，不执行 I/O。

## 12. 异步覆盖层

### 12.1 页面级

页面级任务以画布角落非模态 Overlay 显示阶段与取消入口。不得用全画布半透明遮罩阻止用户查看其他内容，除非当前页面内容确实不安全编辑。

### 12.2 Region 级

- Running：Region 标签显示活动图标和阶段。
- Failed：Critical 边界局部标记，点击/聚焦后 Inspector 显示错误。
- Needs Review：Caution 标记。
- Completed：短暂成功过渡后回到普通状态，避免满屏永久绿色框。

### 12.3 图层替换

- 新图层准备完成前继续显示旧图层，并标记 `正在更新`。
- 成功后 100–160 ms Cross-fade；不得出现一帧空白。
- 失败时保留旧结果，显示可重试错误。
- 请求过期时静默丢弃，不闪烁。

## 13. 文本渲染预览

- 画布预览与导出请求的图层快照共同使用 `manga_rendering::TextLayoutEngine/TextRasterizer`，确保换行、glyph、字重、字距、颜色、描边和 overflow 一致；Data Exporter 本身只合成快照。
- 排版和栅格化在 `paint()` 外按 Region 预计算；`TextLayerItem::paint()` 只绘制缓存的 `QPixmap` 或轻量 glyph cache，不调用 Port、Domain 或文件系统。
- 高倍率缩放时文字与边缘必须保持清晰；质量切换使用 Cross-fade，不能闪白。
- 字体缺失、溢出、字形缺失在 Region 上显示 Caution，不把错误文字直接烧入清理层。
- 编辑译文时即时预览；IME composition 文本可显示为临时下划线，但不得作为最终文本处理。

## 14. 对比模式

- V0.1 使用左右并排视图：左侧原图，右侧翻译结果。
- 两侧始终显示简短标签，保持同一页、同一缩放比例和对齐的页面中心。
- 用户在任一侧缩放、平移或切页时，另一侧同步响应；不提供两套独立滚动状态。
- 两侧之间保留清晰但克制的分隔，不显示可拖动擦拭 Handle。
- 两侧固定显示只读 Region 轮廓，不显示 Handle、Hover 编辑状态或编辑入口，也不提供显示开关。
- Region 编辑禁用；选择可保留但不绘制 Handle。
- 离开对比模式恢复之前工具和 Region 可见偏好。
- 滑块擦拭比较属于后续版本。

## 15. 空、加载和错误

### No project

中央显示 `打开或创建项目以开始编辑`，按钮 `打开项目`。不显示空页面边框。

### No page

显示 `项目中还没有页面`，按钮 `导入页面`。

### Loading page

页面原位置显示 ProgressRing 和文件名；上一页内容必须清除，避免误认为已切页。

### Decode error

显示错误占位、原因、重试和定位文件。Region Overlay 不显示。

### Missing source

显示 `源图像已移动` 和 `重新定位`。不销毁项目中的 Region 和译文。

## 16. 性能体验

- 指针交互和视口绘制目标 60 FPS；最低不得因后台任务持续阻塞。
- OCR、翻译、导入、导出或全页排版期间，缩放、平移和选择仍保持响应。
- 大图和大量 Region 不得导致内存无上限增长。
- 当前页文字渲染缓存按像素字节成本限制为 128 MiB；只修改一个 Region 时不得重排整页其他 Region。
- 可视区外复杂 Overlay 可降低细节，但选择和无障碍信息仍保持。
- 高频进度更新不得造成画布跳动；几何拖动必须紧跟指针。

## 17. 键盘与无障碍

- 画布本身是一个 Tab Stop；内部 Region 使用方向键/Tab 虚拟导航，不让数百 Item 全进入窗口 Tab 顺序。
- 可访问树包含当前页和可见/选中 Region，暴露 ID、原文摘要、译文摘要、状态和几何。
- Enter 打开 Region 编辑；Context Menu 键打开 Region 菜单。
- 屏幕阅读器模式下提供 Region 列表式替代导航，与画布选择同步。
- 颜色状态有文本替代。
- 高对比度下页面边界、Region 和 Handle 使用系统颜色与足够描边。

## 18. 验收清单

- 所有坐标变换在 5%、100%、1600% 与高 DPI 下正确。
- 缩放锚点稳定，切换异步图层不跳视口。
- 创建/移动/缩放一次对应一个 Undo Command。
- 任务完成、失败和过期不会重置选择或覆盖人工修改。
- 300 个 Region 时可流畅平移和选择。
- 原图/清理/翻译/对比模式切换无空白闪烁。
- 仅键盘可遍历 Region、编辑译文并返回画布。
