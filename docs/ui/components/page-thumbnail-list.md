# PageThumbnailList 自定义控件设计

## 1. 控件定位

`PageThumbnailList` 参考 WinUI 3 `ListView` 的选择、滚动、虚拟化和键盘行为，并增加漫画页面状态、惰性缩略图、当前编辑页和后台任务联动。

它是编辑器 Pane 的主要内容，也可在导出页面范围选择等场景复用。列表内容始终反映当前项目的页面顺序、选择和处理状态。

## 2. 解剖

1. Pane Header。
2. 可选搜索/筛选条。
3. Virtualized List。
4. 可选底部页面计数或批量选择摘要。

完整行包含：

- 页面缩略图。
- 页码/显示名。
- 文件名或简短状态。
- Page Status 图标。
- 可选进度。
- Hover/Focused 时的 Overflow Button。

紧凑行只显示缩略图、页码角标和状态角标。

## 3. 缩略图

- 保持源页比例，放入固定大小容器；不裁掉漫画内容。
- 背景为中性色，透明图像可显示棋盘格。
- 未加载时显示固定尺寸占位；列表几何不得因加载完成改变。
- 解码失败显示错误图标和 ToolTip。
- 返回当前页、可视区和相邻页面时，应尽量避免重复显示加载占位。
- 缩略图异步载入；迟到的旧缩略图不得覆盖已经切换或更新的页面。

## 4. 行状态

| 状态 | 表达 |
| --- | --- |
| Unprocessed | 次级文字 `未处理` |
| Queued | 队列图标 + `已排队` |
| Running | 小型活动指示 + 具体阶段 |
| Completed | 勾号 + `已完成` |
| Reviewed | 双勾/确认图标 + `已校对` |
| NeedsReview | Caution 图标 + `需要检查` |
| Failed | Critical 图标 + `失败` |
| MissingSource | 文件警告 + `源文件缺失` |

后台任务状态不改变行高度。失败和需要检查可在导航/筛选中汇总为 `InfoBadge`，但行仍有文本。

## 5. 选择模型

- `currentPageId`：唯一当前编辑页。
- `selectedPageIds`：批量命令选择，可包含当前页。
- 单击行更新 current + selected 单项。
- Ctrl+单击只切换批量选择成员，不切换当前页。
- Shift+单击只选择连续范围，不切换当前页。
- 点击空白不清除当前页，避免编辑器无页面。

当前页使用 Accent 指示器和选中背板。批量选中但非当前页使用较弱背板。键盘焦点有独立焦点框。

## 6. 页面切换

1. 用户激活新页。
2. 目标页立即进入明确的 Loading 状态。
3. Canvas 清除旧页或显示明确过渡占位，不让旧页假装为新页。
4. 页面成功加载后渲染并恢复视图偏好。
5. 加载失败时行进入 Failed/Partial，Canvas 显示错误占位；选择仍停留在该页以便修复。

快速连续选择时只显示最后目标页。旧解码结果不得覆盖新页。

## 7. 滚动与跟随

- currentPage 由外部命令变化时滚入视图，使用 180–240 ms 平滑滚动；减少动画时即时。
- 用户正在拖动滚动条或滚轮滚动时，不自动抢回当前页。
- 后台任务当前页变化不强制列表跟随，除非用户开启 `跟随批处理`。
- 拖动重排时自动滚动边缘，速度随指针靠近边缘增加并设上限。

## 8. 重排

- 长按/拖动行进入重排。
- 显示插入指示线和半透明 Drag Preview。
- 多选拖动保持相对顺序。
- 松开后提交一次 `reorderPages` Intent。
- 正在批处理的任务若依赖当前顺序，重排禁用并说明原因。
- 重排可 Undo。

## 9. 搜索与筛选

- Header 搜索参考 `AutoSuggestBox`。
- 搜索页码、文件名和状态；不默认搜索 OCR 全文，避免昂贵与隐私含义不明。
- 筛选可用 `MenuFlyout`：全部、未处理、处理中、需要检查、失败、已校对。
- 过滤不改变 currentPage；若当前页被过滤隐藏，Header 显示 `当前页已被筛选隐藏` 与清除筛选动作。

## 10. 上下文命令

参考 `MenuFlyout`：

- 打开。
- 在文件夹中显示。
- 运行检测/OCR/翻译。
- 标记已校对。
- 导出。
- 替换源图。
- 从项目移除。

对多选时菜单文案显示对象数量，例如 `翻译 12 页`。危险操作置于分隔符后。

## 11. 响应式

- 完整 Pane：行高 84–96 px，缩略图约 56×72 px。
- 紧凑 Pane：宽 80–96 px，行高 104–120 px，缩略图居中，文字仅页码。
- Overlay：宽 260–320 px，选择页面后自动关闭可由设置控制；默认窄屏自动关闭。
- 触摸模式增加行高与命中区，但缩略图不必放大到挤压列表。

## 12. 键盘与无障碍

- 上下键移动焦点；Enter/Space 激活；Ctrl/Shift 扩展选择。
- Home/End 到首尾；PageUp/PageDown 按可视页移动。
- Delete 移除页面，但焦点在文本输入时不拦截。
- 行可访问名称包含页码、文件名、当前/选中、处理状态。
- 缩略图本身为装饰；OCR/译文不作为图片替代文字朗读。
- 重排提供键盘命令：Alt+Up/Down 或上下文菜单 `上移/下移`。

## 13. 验收清单

- 1、28、500、5000 页时虚拟化和滚动稳定。
- 缩略图乱序返回不串页。
- current 与 multi-selection 视觉语义不混淆。
- 过滤隐藏当前页时有明确反馈。
- 运行中状态更新不改变滚动位置和行高度。
- 键盘可选择、批量选择、重排和打开菜单。
