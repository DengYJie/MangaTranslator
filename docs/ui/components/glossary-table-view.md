# GlossaryTableView 自定义控件设计

## 1. 控件目标

`GlossaryTableView` 用于浏览和选择术语。它需要同时表达原文、固定译法、类型、来源和状态，并支持排序、批量选择、大数据量浏览和完整的表格无障碍语义。

WinUI 3 本体没有可直接引用的第一方 DataGrid，因此本控件独立定义其外观、功能和行为。

## 2. 内容与列

标准列顺序：

1. 原文。
2. 固定译法。
3. 类型。
4. 来源。
5. 状态。

不同术语视图的内容：

- `全局术语`：来源显示 `全局`，允许编辑和批量操作。
- `当前项目`：来源显示当前项目名，允许编辑和批量操作。
- `有效术语`：显示最终采用的译法和真实来源，只读。

排序、筛选和内容刷新后，只要条目仍然存在，就应保留其选择和合理焦点。

## 3. 尺寸与布局

- Header 高度 36–40 px。
- 行高 52–60 px，状态变化不得改变行高。
- 原文与固定译法是主要内容列，共同获得剩余宽度。
- 类型、来源和状态使用受限宽度，避免挤占译文。
- 原文和固定译法必须保留可理解的最小宽度。
- 用户可以调整列宽；不同术语视图分别记住列宽偏好。
- 长文本单行省略，完整内容通过 ToolTip 和无障碍文本提供。

默认不显示完整纵横网格线。优先使用间距、行间细分隔线、Hover 和 Selected 背板表达层级，避免传统数据库工具的厚重网格感。

## 4. Header 行为

- 只有支持排序的列才表现 Hover、Pressed、焦点和排序箭头。
- 首次激活使用自然升序，再次激活改为降序。
- 必须提供返回默认术语顺序的明确入口。
- 调整列宽的分隔位置应有足够命中区，并显示调整光标。
- Header 向辅助技术说明列名、排序方向和可操作状态。

## 5. 选择与编辑

- 默认整行单选；Ctrl/Shift 支持多选。
- 单击选中行，并在右侧 Pane 显示编辑内容或解析详情。
- 双击或 Enter 打开编辑。
- `有效术语`中的编辑动作先定位到真实来源。
- 不在单元格中直接编辑，避免与右侧编辑 Pane 形成两套提交和验证体验。
- 多选时右侧 Pane 显示批量摘要，只提供适用于全部所选条目的操作。
- 点击空白区域不得静默丢弃含未保存修改的编辑内容。

## 6. 行视觉状态

### Rest

使用内容 Surface、主要前景和次要前景。行内容保持稳定，不因后台状态变化跳动。

### Hover

整行使用低强度 Hover Fill，颜色过渡 80–120 ms。

### Selected

使用 Selected 背板和清晰前景。键盘焦点框与选择背板分离，焦点不等于选择。

### Project override

项目术语覆盖全局术语时，来源列显示项目名以及 `覆盖全局` 文本或 Badge。它属于正常覆盖关系，不使用错误色。

### Conflict / Needs review

使用警告或严重错误语义图标、文字和颜色。冲突不能只靠颜色表达。

### Disabled

禁用条目仍可阅读、搜索和编辑，状态列显示 `已禁用`；它不会进入翻译请求。

## 7. 键盘行为

- Tab 进入表格后聚焦当前行或第一行。
- 上/下键移动行，左/右键移动当前逻辑列。
- Home/End 到行首尾；Ctrl+Home/End 到表格首尾。
- Space 切换行选择；Ctrl/Shift 扩展多选。
- Enter 打开编辑或来源详情。
- Delete 删除持久术语视图中的选择；在有效术语视图不可用。文本输入或 IME 组合期间不得拦截。
- Shift+F10 打开当前行菜单。

## 8. 排序、筛选与内容更新

- 10,000 条术语时仍应保持流畅滚动、排序和筛选。
- 搜索输入使用 150–250 ms 防抖。
- 内容更新不得让滚动位置无故跳回顶部。
- 项目切换后，旧项目迟到的搜索或解析结果不得覆盖当前项目内容。
- 排序和筛选不能清空仍然存在的选择。
- 高频状态更新不得造成列宽、行高或焦点跳动。

## 9. 响应式呈现

### Table mode `>=720`

- 使用稳定的多列表格。
- `720–1007` 时可以缩短来源文字或隐藏状态文字，但必须保留完整 ToolTip 和无障碍名称。
- 关键字段不能依赖横向滚动才能发现。

### Card mode `<720`

- 切换为两行卡片：第一行 `原文 → 固定译法`，第二行显示类型、来源和状态。
- 卡片模式保持相同的数据、选择、排序和命令语义。
- 进入和退出卡片模式不得丢失选择、焦点和筛选。

## 10. 主题与视觉质量

- 背景、Hover、Pressed、Selected、前景、分隔线、焦点和状态使用 Fluent 语义颜色。
- Light、Dark 和高对比度下都应保持清晰的行、列、选择和焦点边界。
- 不使用交替高饱和行色。
- 200% 文本缩放时允许行高增长或减少次要列，不能裁切关键内容。

## 11. 无障碍

- 控件提供表格语义、行列数量、当前单元格和选择状态。
- 每行的可访问名称包含原文、译文、类型、来源和状态。
- 每个逻辑单元格与对应列 Header 建立语义关联。
- 有效术语必须播报真实来源以及覆盖或冲突状态。
- 排序、筛选和内容刷新不得无故夺取焦点。

## 12. 验收清单

- 0、50、10,000 条数据下布局、滚动和选择稳定。
- 排序、筛选、列宽调整后仍能恢复有效选择。
- 全局、项目和有效术语使用正确的编辑权限。
- 项目覆盖与冲突具有不同且清晰的视觉语义。
- 720 px 附近切换 Table/Card 模式不丢选择、焦点和筛选。
- 仅键盘可以选择、排序、打开编辑和访问菜单。
- Light、Dark、高对比度、200% 文本缩放和屏幕阅读器通过检查。
