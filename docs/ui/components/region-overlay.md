# RegionOverlay 自定义控件设计

## 1. 控件定位

`RegionOverlay` 在 MangaCanvas 上表达一个文本区域，包含区域边界、标签、状态、选择柄和工具预览。

一个 RegionOverlay 对应稳定 Region ID。内容刷新或排序变化不能让它变成另一个区域。

V0.1 只显示和编辑轴对齐矩形。旋转 Handle、顶点 Handle 和多边形行为属于后续版本，在 V0.1 界面中不出现。

## 2. 解剖

从底到顶：

1. Hit Area：透明扩展命中区。
2. Region Fill：低透明度语义填充。
3. Boundary：V0.1 为矩形边界。
4. Status Decoration：低置信度、运行、失败、溢出。
5. Label：Region ID、顺序或阶段摘要。
6. Selection Boundary。
7. Resize Handles。

非选中 Region 不长期显示所有 Handle 和大标签，避免遮挡漫画。

## 3. 视觉状态

### 3.1 Rest

- 边界 1 px，缩放补偿后保持可见但不随画布无限变粗/变细。
- 填充透明度很低。
- 标签按用户偏好隐藏或只显示序号。

### 3.2 Hover

- 100 ms 内边界增亮或增至 1.5–2 px。
- 显示紧凑标签：`03 · 已翻译`。
- 指针根据可操作部位变化。
- Hover 不改变当前选择。

### 3.3 Selected

- Accent 边界 2 px。
- 显示 Handle。
- Label 固定显示。
- 若 Inspector 有焦点，画布 Selected 仍保留；不要因焦点离开画布消失。

### 3.4 Primary Selected in multi-selection

- 主选择使用 Accent 实线和完整 Handle。
- 其他选中项使用较弱 Accent 边界，不显示独立 Handle。
- 批量移动时所有选择都有统一预览位移。

### 3.5 Disabled / Locked

- 边界使用次级色和锁图标。
- 不响应移动/缩放，但可选择和查看。
- ToolTip 说明锁定原因：任务运行、图层只读或权限限制。

## 4. 状态装饰

状态可组合，但最多同时呈现一个主状态图标和一个辅助标记，避免标签堆叠。

| 状态 | 边界/图标 | 文案 |
| --- | --- | --- |
| LowConfidence | Caution 虚线或角标 | `OCR 置信度低` |
| Running | 活动点/小型环 | `正在翻译` 等具体阶段 |
| Failed | Critical 图标 | `翻译失败` |
| NeedsReview | Caution 图标 | `需要检查` |
| Overflow | Caution 下划线/角标 | `译文溢出` |
| ManualOverride | 小型编辑标记 | `人工修改` |
| Completed | 短暂勾号 | `已完成`，随后回普通状态 |

`Completed` 不长期把所有 Region 变绿。错误和需要检查状态持续到解决或明确忽略。

## 5. 命中测试

优先级从高到低：

1. Resize Handle。
2. Selection Boundary。
3. Region 内部。
4. 重叠 Region 中更小或更靠上的候选。

命中区不等于视觉大小：

- Handle 视觉 8 px，鼠标命中建议 12–16 px。
- 触摸优化视觉 10–12 px，命中至少 24 px。
- 边界线视觉 1–2 px，命中带宽至少 6–8 px。

多个 Region 重叠时：

- 首次点击选择最上层/最小包含 Region。
- 再次点击同位置可循环候选，或通过右键菜单 `选择重叠区域`。
- Alt+滚轮循环等高级手势不作为首版唯一入口。

## 6. Handle 设计

### 6.1 矩形 Region

- 四角 Handle：同时改变宽高。
- 四边中点 Handle：只改变单轴。
- Handle 使用中性填充 + Accent 描边，Hover 反转或增强。

### 6.2 后续几何类型

V0.1 不显示旋转或多边形编辑能力。后续版本加入时，顶点、边中点和旋转 Handle 必须与矩形 Handle 有清晰区分，并为添加、删除和保持合法几何提供可理解反馈。

### 6.3 缩放补偿

Handle 在屏幕空间保持近似固定大小，不随画布缩放变得不可点击。低缩放下 Handle 过密时：

- 只显示四角 Handle。
- 放大后显示全部矩形 Handle。

## 7. 移动

1. 指针在 Region 内按下并超过拖动阈值。
2. 捕获指针，显示移动光标。
3. 更新预览几何；Inspector 数值可节流显示。
4. 可选吸附页面边缘、中心和相邻 Region 边缘；吸附发生时显示辅助线。
5. 松开后通过 Intent 提交一次移动。

修饰键：

- Shift：限制到水平或垂直主轴。
- Alt：禁用吸附。
- 方向键：1 源像素移动；Shift+方向键：10 像素。若缩放极低，仍以源像素为单位。

Region 始终限制在页面内。编辑到页面边缘时停止在边界，不允许形成越界几何。

## 8. 缩放

- 拖角 Handle 改变两轴。
- 拖边 Handle 改变单轴。
- Shift 保持宽高比。
- Alt 从中心缩放；是否采用需在 ToolTip 和教学提示明确。
- 最小尺寸为 2×2 源像素，不允许翻转宽高。
- 拖过对边时 Clamp 到最小值，不把 Handle 角色突然交换。

自动排版开启时，Resize 触发轻量排版预览；高成本最终排版在手势结束后执行。

## 9. 标签

标签内容按优先级：

1. 阅读顺序号或 Region ID。
2. 当前阶段/错误状态。
3. 可选置信度。

标签位置：

- 优先在 Region 上方左侧。
- 空间不足时置于 Region 内上缘。
- 页面边缘 Clamp，不能被 Viewport 裁切。
- 多个标签重叠时，只保留选中/悬停标签，其余退化为序号角标。

标签 Surface 使用高对比前景和 4 px 圆角；不能把标签文字绘制进导出图层。

## 10. 上下文菜单

参考 WinUI 3 `MenuFlyout`：

- 编辑译文。
- 运行 OCR。
- AI 重译。
- 重新排版。
- 复制原文 / 复制译文。
- 调整阅读顺序；V0.2 提供该能力后显示。
- 复制 Region。
- 恢复自动区域。
- 删除区域。

菜单按当前区域状态启用或禁用。破坏性删除置于分隔符后。可通过 Undo 恢复时不每次弹 ContentDialog。

## 11. 动效

- Hover/Selected 边界颜色与填充 80–120 ms。
- Handle 出现 100 ms 淡入，不做弹跳缩放。
- 状态从 Running 到 Completed：环转为勾号或 Cross-fade，240 ms，勾号 800–1200 ms 后淡出。
- Failed 状态不闪烁、不持续脉冲。
- 自动结果导致几何变化且未与用户手势冲突时，可使用 160 ms 平滑过渡；人工输入和 Undo/Redo 即时或使用极短过渡。

减少动画时所有几何与 Handle 变化即时。

## 12. 冲突处理

- 用户拖动时收到同 Region 异步几何结果：暂存结果，不改变正在拖动的预览；松手后比较版本。
- 人工几何优先，自动结果进入候选或可恢复记录。
- Region 被外部删除：取消手势，清除选择，Inspector 显示 `区域已被移除` 的短暂状态。
- 当前 Region 被移除后，对应 Overlay 必须同时消失，不能保留不可操作的幽灵区域。

## 13. 无障碍

- Region 可访问名称：`区域 03，原文……，译文……，需要检查`。
- 可访问状态：选中、锁定、运行、失败、人工修改。
- 提供 Move/Resize 的键盘替代和 Inspector 数值输入替代。
- Handle 不全部作为独立 Tab Stop；进入“调整区域”模式后，方向键与快捷键操作当前 Handle，并播报几何变化。
- 低置信度和错误同时有文本。
- 高对比度下使用系统 Highlight/HighlightText 等语义色。

## 14. 验收清单

- 缩放 25% 与 800% 时 Handle 均可命中。
- 重叠、2×2 最小尺寸和页面边缘的矩形 Region 可选择。
- 拖动期间不产生数百 Undo Command。
- 异步结果不打断手势、不覆盖人工几何。
- 标签不进入导出结果、不被页面边缘裁切。
- 多选主选择与次选择清晰区分。
- 键盘可完成移动、缩放、删除和上下文命令。
