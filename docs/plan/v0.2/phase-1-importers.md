# V2-P1：安全归档与 PDF 导入

> 状态：Planned
> 前置阶段：V2-P0 导入 DTO、错误码和 V0.2 Schema 已冻结
> 输出：不覆盖源文件、受资源上限保护且可部分诊断的 CBZ/ZIP/PDF 导入

## 1. 阶段边界

本阶段扩展输入来源，不实现检测、OCR、Inpaint 或页面流水线。导入只生成与普通图片导入一致的项目页面和相对源资产；缩略图、检测和 OCR 由后续阶段按需运行。

V0.2 支持 ZIP/CBZ 和 PDF。CBR、CB7、加密归档、嵌套归档、PDF 文本抽取和矢量保真编辑不在本阶段。

## 2. ZIP/CBZ Adapter

### 2.1 发现与校验

- [ ] 通过 libarchive 读取 Entry，不根据扩展名假定内容安全。
- [ ] 只接受规范化后位于归档根内的 regular file；拒绝绝对路径、盘符、UNC、`..` 穿越和 NUL。
- [ ] 拒绝 symlink、hardlink、device、FIFO、socket 和其他特殊 Entry。
- [ ] 不递归打开归档内归档；加密 Entry 返回稳定不支持错误。
- [ ] 图片使用内容探测和 Qt 解码验证；伪装扩展名不进入项目。

### 2.2 资源上限

- [ ] Entry 数不超过 10,000。
- [ ] 单 Entry 解压大小不超过 256 MiB，总解压大小不超过 2 GiB。
- [ ] 已知压缩大小时限制压缩比不超过 100:1；未知大小时以流式字节计数硬停止。
- [ ] 规范化路径深度不超过 32；文件名和路径长度使用明确上限。
- [ ] 超限后停止读取，清理 staging，不留下半导入项目或未引用资产。

### 2.3 顺序与提交

- [ ] 路径段做 Unicode NFKC 比较键和确定性自然排序，同时保留原 Entry 名用于诊断。
- [ ] 同一比较键冲突使用完整规范路径和原始 Entry 序号稳定破局。
- [ ] 先写独立 staging，所有选中页面验证成功后再以现有导入事务提交。
- [ ] 单个损坏图片默认形成可审阅的页面级失败列表；用户确认继续后只提交有效页面。

## 3. PDF Adapter

- [ ] 使用 Qt 6.11 `QPdfDocument`，等待 load status 后再枚举页面。
- [ ] 默认以 300 DPI 计算 raster size，保持页面纵横比，不做文本或矢量元素抽取。
- [ ] 单页限制 32 MP、最长边 8,192 px、估算工作集 512 MiB；超过时在允许范围内降 DPI 并明确报告。
- [ ] 密码保护、权限拒绝、损坏文档和不支持特性映射到稳定错误。
- [ ] 页面按 PDF 原顺序导入；单页渲染失败可由用户选择跳过，不能改变其他页编号的相对顺序。
- [ ] 渲染在工作线程执行，QImage 作为值返回；GUI 线程不阻塞且 QPdfDocument 的线程归属明确。
- [ ] 每页先写 staging 图片并校验可重读，再交给与普通图片相同的项目导入事务。

## 4. UseCase 与 UI 边界

- [ ] `ImportArchiveUseCase` 和 `ImportPdfUseCase` 捕获不可变设置、目标项目 revision 和 stop token。
- [ ] 进度以“扫描/验证/解码或渲染/提交”阶段报告，未知总量不得伪造百分比。
- [ ] 取消发生在提交前时删除 staging；提交后只报告已经完成的原子结果。
- [ ] UI 只展示来源、页数、失败项、资源限制和恢复动作，不接触 libarchive/QPdfDocument 类型。
- [ ] 项目 Dirty、Undo 和保存语义与 V0.1 图片导入一致；导入一组页面是一个复合命令或明确不可撤销事务，不混用。

## 5. 测试

- [ ] ZIP Slip、绝对/盘符/UNC 路径、NUL、深路径、链接和特殊 Entry。
- [ ] Entry 数、单文件、总大小、压缩比和流式未知大小上限。
- [ ] Unicode NFKC、大小写、自然数字、多目录和冲突键排序。
- [ ] 空归档、非图片归档、损坏图片、错误扩展名、取消和磁盘不足。
- [ ] PDF DPI/纵横比、透明度/颜色、32 MP/8,192 px/512 MiB 限制和逐页失败。
- [ ] staging 清理、原子提交、源归档/PDF 哈希不变和保存重开顺序一致。
- [ ] fuzz/恶意 fixture 必须自制或具有可记录许可，不提交用户漫画。

## 6. 退出条件

- 安全 fixture 通过且恶意 Entry 不会写出 staging 根目录。
- 大小、数量、比例和内存上限在读取过程中生效，不依赖事后检查。
- CBZ/ZIP/PDF 与普通图片最终生成相同的页面资产合同和稳定顺序。
- 取消、部分失败、磁盘不足和保存失败不破坏已有项目或源文件。
- GUI 线程无归档解压、PDF rasterize 或同步磁盘长任务。

## 7. 完成证据

记录 fixture 清单、来源/许可证、安全测试矩阵、峰值内存、取消与故障注入结果，以及导入后项目 round-trip。检测和缩略图生成不作为本阶段完成条件。
