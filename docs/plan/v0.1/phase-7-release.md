# P7：稳定性与发布验收

> 状态：Planned  
> 前置阶段：P6  
> 输出：满足 V0.1 Definition of Done 的 Windows x64 发布候选

## 目标

证明 V0.1 是可恢复、可诊断和可持续演进的纵向切片，而不只是正常路径演示。

## TODO

### 自动验证

- [ ] 运行 Domain、Application、Service、Data、Network、UI、Contract 和 Integration 测试。
- [ ] 覆盖项目保存/恢复、Schema、坐标转换、Undo/Redo、过期结果和导出。
- [ ] 使用固定样本验证 PNG/JPEG 单页与批量导出。
- [ ] 运行 Debug、Release 和 Test Preset；记录实际命令和结果。
- [ ] 验证 Windows 10 22H2 与 Windows 11 x64 支持环境。

### 手工与视觉验收

- [ ] Light、Dark、正常/窄宽度、高 DPI 和文本缩放。
- [ ] 键盘主线、焦点顺序、IME、快捷键和错误恢复。
- [ ] 长页面、大量 Region 和长文本的响应性。
- [ ] 模型缺失、网络离线、凭据失败、磁盘不足和只读目录。
- [ ] 关闭页面、项目和应用时无崩溃、假成功或错误写回。

### 数据安全与隐私

- [ ] 源图哈希在完整工作流后保持不变。
- [ ] 项目、QSettings、日志、诊断和导出元数据不含密钥。
- [ ] 默认日志不含完整漫画图片、原文或译文。
- [ ] `.bak` 恢复和损坏项目提示可执行且不覆盖原数据。
- [ ] 模型权重、用户漫画、缓存和本机绝对路径不进入 Git 或发布清单错误位置。

### 发布准备

- [ ] 使用 Release Preset 构建并通过 `windeployqt` 准备便携 ZIP。
- [ ] 列出 Qt、FluentQt、VC Runtime、第三方库和模型的许可证与打包边界。
- [ ] 模型未通过再分发审核时，不随包提供，并验证下载/人工兜底体验。
- [ ] 编写 V0.1 版本说明、已知限制、项目备份和凭据说明。
- [ ] 从干净目录解压并完成首次启动及主线烟雾测试。

## V0.1 发布门槛

- [ ] 创建/打开、导入、框选、OCR/人工录入、翻译/人工录入、清除、排版、保存重开和导出全部通过。
- [ ] 用户可见编辑可撤销；保存不清空 Undo 历史。
- [ ] 后台任务不阻塞 GUI，不覆盖新项目或人工修改。
- [ ] 保存/导出失败不破坏最后有效数据，不覆盖既有文件。
- [ ] 所有相关测试通过，未运行项有明确原因和风险说明。
- [ ] 没有把 CBZ/PDF、自动检测、复杂 Inpaint、流式翻译或 V0.3 能力混入发布范围。

## 退出条件

- V0.1 路线图完成标准和仓库 Definition of Done 均满足。
- 发布清单、已知限制、验证结果和未验证边界齐全。
- V0.2 可以建立在稳定 Region、项目格式、Undo/Redo 和异步协议上，无需推翻 V0.1 主线。

## 注意事项

- 不以降低错误可见性或跳过恢复测试换取发布。
- 发现阻断级数据安全问题时回到责任阶段修正并重新执行相关验收。
- Agents 不创建或推送 Git Commit，除非用户另行明确授权。
