# P6：纵向切片集成

> 状态：Planned
> 前置阶段：P3、P4、P5
> 输出：使用真实图片、项目仓储和处理适配器的端到端 V0.1 主线

## 目标

通过 `ApplicationContext` 连接所有层，验证真实用户工作流，而不是继续扩展孤立功能。

## TODO

### Composition Root

- [ ] 由 `ApplicationContext` 构造 Repository、Importer、处理适配器、UseCase、ViewModel 和窗口。
- [ ] 明确对象所有权、销毁顺序、线程归属和关闭流程。
- [ ] 初始化 DPI、Qt、FluentQt、资源、字体、日志、设置和主题。
- [ ] 不在 Composition Root 之外创建第二套生产依赖图。

### 端到端主线

- [ ] 创建项目并选择保存目录、语言和阅读方向。
- [ ] 导入单图与图片文件夹并切换页面。
- [ ] 创建/编辑 Region，人工录入原文与译文。
- [ ] 对 Region/页面执行 OCR 并采用结果。
- [ ] 发送单页翻译并按 Region ID 校验、预览和采用。
- [ ] 创建纯色清除层并应用基础横排/竖排布局。
- [ ] 覆盖所有用户可见修改的 Undo/Redo。
- [ ] 保存、关闭、重新打开并恢复当前项目内容。
- [ ] 导出当前页、选中页和全部页面为 PNG/JPEG。

### 生命周期与故障

- [ ] 页面切换时任务可被发现，结果只发布给正确页面。
- [ ] 关闭项目时取消等待并拒绝迟到结果。
- [ ] 应用退出时停止接受新任务并安全收尾。
- [ ] 保存、模型、网络、清除、排版和导出失败都有可执行恢复入口。
- [ ] 导出结果不覆盖既有文件；冲突处理由 P4 `IComicExporter` 实现。

## 集成测试

- [ ] 纯人工主线，无 OCR/网络也能完成保存和导出。
- [ ] OCR + 人工译文主线。
- [ ] 人工原文 + LLM 翻译主线。
- [ ] OCR + LLM + 清除 + 排版完整主线。
- [ ] 保存不清空当前会话 Undo/Redo；关闭并重新打开后项目内容一致，Undo 历史重新开始（V0.1 不做 Undo 持久化）。
- [ ] 项目切换、取消、迟到结果和人工修改冲突。
- [ ] 单页失败不破坏其他页面和原项目。
- [ ] 页面图像正常加载并显示；缺失或损坏时返回可恢复错误。
- [ ] 加载失败时画布显示占位状态，不残留上一页图像。
- [ ] 页面快速切换时迟到的 `QImage` 不覆盖当前页面。

## 退出条件

- 使用代表性真实图片稳定走通 V0.1 主线。
- 重开后页面、Region、文字、排版、图层和人工修改一致。
- 导出结果与编辑器预览在支持范围内一致。
- 任一自动能力不可用时，人工编辑与导出仍然成立。

## 注意事项

- P6 以修复契约和集成缺口为主，不新增 V0.2 功能。
- 不用“演示成功”代替失败、取消、关闭和恢复测试。
- 发现跨层依赖倒置时回到对应阶段修正，不在 Composition Root 添加业务补丁。
