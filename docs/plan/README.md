# 实施计划

本目录保存按版本拆分的实施计划。计划以完成标准和依赖关系为准，不承诺发布日期。

## 版本计划

| 版本 | 文档 | 目标 |
| --- | --- | --- |
| V0.1 | [V0.1 人工辅助翻译闭环](v0.1/README.md) | 完成导入、区域编辑、OCR/人工录入、翻译、排版、保存和导出 |

## 使用规则

- 每个阶段完成后必须满足对应退出条件，才能进入依赖它的阶段。
- 阶段内部可并行开发，但不得绕过 Domain、Application Port 和 Composition Root 的边界。
- 计划范围服从对应技术决策文档；未列入 V0.1 的能力不得以临时实现方式加入主线。
- 发现数据格式或公共接口需要变化时，先同步更新技术决策和计划，再修改实现。
- 阶段 TODO 是执行清单，不表示已完成；只有退出条件和验证项同时通过后才能更新状态。
