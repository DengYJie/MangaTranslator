# 常见问题与排错指南 (User FAQ)

### Q1: 如何下载与配置本地 OCR / 检测模型？
- 应用支持通过 ONNX Runtime 运行的漫画文本检测（Comic Text Detector）与文字识别模型（Baberu / PaddleOCR-VL-1.6 ONNX 等）；
- 模型下载至 `models/ocr/<model-name>/1.0.0/` 目录下，并确保包含对应的 `manifest.json` 清单校验文件；
- 如网络下载 HuggingFace 模型较慢，可使用 `https://hf-mirror.com` 镜像端点加速下载。

### Q2: 如何配置 AI 翻译服务？
- 进入「设置」->「AI 翻译」页面；
- 选择 API 供应商（如 OpenAI、DeepSeek、自定义兼容接口等）；
- 填写 API Key、Endpoint 接口地址及模型名称（如 `gpt-4o-mini`, `deepseek-chat`）；
- 点击「测试连接」确保凭据与网络通畅。

### Q3: 软件意外崩溃后，如何恢复未保存的项目数据？
- MangaTranslator 在每次保存时均会自动维护事务性的 `.bak` 备份文件；
- 重新打开该项目时，系统会自动探测并提示发现可用的备份文件，点击「从备份恢复」即可还原至最后一次有效保存状态。

### Q4: 批量处理为什么没有出现单独的页面？
- MangaTranslator 将整章批量工作流整合在编辑器的顶部标题栏菜单中（「处理」->「处理项目」）；
- 在处理过程中，您可以在底部任务条观察进度、取消或暂停，无需在独立页面间跳转。

### Q5: 为什么在设置界面标题栏有一个返回按钮？
- 当您从编辑器或主页进入「设置」时，标题栏左侧会自动呈现返回箭头，点击即可直接返回先前的编辑界面或主页。
