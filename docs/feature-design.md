## 1. 产品定义

MangaTranslator 是面向漫画翻译者、汉化人员和个人创作者的 AI 辅助桌面工作台。产品负责自动完成重复劳动，同时保留人工校对和精细排版能力。

核心价值：

- 将检测、OCR、翻译、清除和排版集中在一个可视化工作流中。
- 使用页面上下文和术语库提升译文一致性。
- 允许用户修正任何自动结果，不把模型输出当成最终答案。
- 对单页和整章任务同时提供可观察、可暂停、可恢复的处理体验。

## 2. 核心用户流程

### 2.1 新建并翻译项目

```text
首页
  -> 新建项目/导入
  -> 选择当前版本支持的来源
  -> 设置源语言、目标语言、阅读方向和引擎
  -> 导入并生成页面列表
  -> 打开编辑器
  -> 自动或手动创建文字区域
  -> OCR
  -> 翻译
  -> 清除原文并排版
  -> 人工校对
  -> 保存/导出
```

### 2.2 整章批量处理

```text
选择页面范围和流水线阶段
  -> 开始任务
  -> 查看每页检测/OCR/翻译/清除/排版状态
  -> 暂停、继续或取消
  -> 重试失败页面
  -> 回到编辑器逐页校对
  -> 批量导出
```

### 2.3 单个文本区域校对

```text
选择画布中的文字区域
  -> 查看原文、置信度和译文
  -> 修正 OCR 或译文
  -> 选择候选或按风格重译
  -> 调整字体、字号、方向、对齐和区域
  -> 画布即时预览
```

## 3. 信息架构与页面

一级导航保持精简：

1. 首页/项目中心。
2. 漫画编辑器。
3. 批量翻译。
4. 术语库。
5. 设置。

“新建项目/导入”是从首页进入的任务流程，不必占用永久一级导航。

### 3.1 首页/项目中心

功能：

- 新建项目/导入。
- 打开已有项目。
- 显示最近项目、缩略图、最近打开时间和处理进度。
- 从最近记录恢复工作。
- 显示模型缺失、项目损坏或源文件移动等可恢复问题。

首版验收：用户可以创建、打开、保存和重新打开一个项目，并回到上次页面。

### 3.2 新建项目/导入

配置项：

- 输入当前版本支持的文件、文件夹或归档来源。
- 项目名称和保存位置。
- 源语言和目标语言。
- 阅读方向：左到右或右到左。
- OCR 引擎。
- 翻译 Provider/模型。
- 是否使用术语表和上下文。

源语言与目标语言相同时允许继续，但显示明确警告，说明该配置适用于校对、重排和再处理。

导入完成后统一形成 `ComicProject -> ComicPage[]`，后续功能不感知原始格式。

### 3.3 漫画编辑器

编辑器是产品的核心工作区：

```text
页面缩略图 | 漫画画布 | Inspector
               ^
          Command Bar
               v
          状态/任务区域
```

建议默认尺寸语义：左侧页面区约 220 px，右侧 Inspector 约 320 px，中间画布自适应；窄窗口依次折叠页面区和 Inspector。

#### 页面面板

- 显示缩略图、页码和处理状态。
- 搜索或定位页面。
- 切换当前页面。
- 页面状态：未处理、处理中、已完成、有问题。
- 重新 OCR、重新翻译、标记完成、导出此页和删除等上下文操作。
- 普通单击切换当前页；Ctrl/Shift 多选只改变批量选择集合，不切换当前页。

#### Command Bar

- Undo/Redo。
- 缩放、适应页面和实际大小。
- 选择、移动/平移和创建文字区域工具。
- 仅检测、仅 OCR、仅翻译、仅清除、重新排版。
- 一键智能翻译。
- 导出和溢出菜单。

“一键智能翻译”是局部主操作，执行检测、OCR、翻译、清除和排版；用户仍能单独运行每个阶段。

#### 漫画画布

- 显示页面和非破坏性处理图层。
- 缩放、平移、适应窗口和页面切换。
- 创建、选择、多选、移动、缩放和删除文本区域。
- 显示 Hover、Selected、Handles、置信度异常和处理状态。
- 支持原图、清理、翻译和对比四种预览模式。
- V0.1 对比模式使用同步的并排视图；滑块对比属于后续版本。
- 支持 Undo/Redo，避免直接破坏原图。

#### Inspector

选中一个文本区域后显示：

- 原文及 OCR 置信度。
- 译文编辑器。
- 源语言、目标语言和区域身份。
- AI 重译及风格选项：更自然、更简短、更口语、保留日式表达、自定义要求。
- 翻译候选，点击即可替换，不强制打开对话框。
- 字体、字号、自动适配、字重、颜色、对齐、横排/竖排、行距和边距。
- V0.1 提供区域 X/Y/W/H 轴对齐矩形调整；旋转和多边形属于后续版本。
- 原文清除方式和恢复自动区域。

Inspector 使用 Expander/Accordion 分组，默认展开“翻译”和“排版”，避免形成超长表单。

### 3.4 批量翻译

配置：

- 页面范围。
- 源语言和目标语言。
- OCR、翻译和清除引擎。
- 是否使用上下文和术语表。
- 上下文失败后是否明确降级为纯单页翻译，默认关闭。
- 是否自动清除、自动排版和自动导出。
- 并发度或性能档位。

任务视图：

- 显示总页数、已完成数量、总进度和当前阶段。
- 每页分别显示检测、OCR、翻译、清除和排版状态。
- 支持暂停、继续、取消。
- 支持仅重试失败项。
- 显示 `interrupted`、`stale` 和 `blocked`，并允许用户选择恢复或重新处理。
- 允许用户离开页面，后台任务状态仍可在应用底部查看。
- 任务完成后引导进入人工校对，而不是直接宣称结果最终可用。

### 3.5 术语库与 Translation Memory

功能：

- 添加、编辑、删除和搜索术语。
- 类型：人名、地名、组织、技能、头衔、物品、专有名词和自定义。
- 术语库不依赖项目即可进入；无项目时管理全局术语。
- 支持独立的全局术语和随项目保存的项目术语。
- 打开项目后提供 `有效术语`、`当前项目`、`全局术语` 三个视图；有效术语是只读合并结果，不是第三份存储。
- 同一规范化源词存在项目术语时覆盖全局术语，并保留最终采用来源。
- 翻译请求自动携带启用的有效术语，内容必须与 UI 的有效术语视图一致。
- 检测同一源词的冲突译法。
- 支持别名组、禁止翻译、完整词/字面匹配、停用和引用保护。
- 支持 CSV 导入导出；冲突逐项显示，禁止无提示批量覆盖。
- 从项目中自动提取候选术语不属于 V0.3 必选能力。

V0.3 交付完整的全局与项目术语工作流，包括增删改查、确定性覆盖、来源追踪和翻译注入。术语修改只将已有译文标记为需要检查，不自动改写。TM 与术语分离，默认展示建议；只有人工确认或明确采用的译文可以进入全局 TM，模糊命中不能自动覆盖。

### 3.6 设置

分类：

- OCR：引擎、模型、语言和阈值。
- 翻译：Provider、模型、Prompt、上下文长度和输出风格。
- 网络：Endpoint、代理、超时和重试。
- 模型：下载、校验、存储位置和执行 Provider。
- 排版：默认字体、字号范围、方向、边距和行距。
- 外观：Light/Dark/System、Accent、字体缩放。
- 性能：CPU/GPU、线程数、缓存大小和显存策略。
- 隐私：日志内容、远程发送提示和历史清理。

密钥必须安全存储，界面只显示掩码状态，不回显完整值。

## 4. 核心处理能力

### 4.1 输入格式

优先级：

| 阶段 | 格式 |
| --- | --- |
| P0 | JPG/JPEG、PNG、WEBP、图片文件夹 |
| P1 | CBZ/ZIP、PDF |
| P2 | CBR、CB7、Fixed Layout EPUB |
| P3 | 特殊平台格式 |

BMP、TIFF 可利用 Qt 图像能力按实际需要补充。私有加密格式不作为近期目标。

导入要求：

- 自然排序页面。
- 支持 Unicode 路径。
- 防止压缩包路径穿越和资源炸弹。
- 明确处理 EXIF 方向、颜色空间和失败页面。

### 4.2 文字检测

- V0.1 以手工矩形 Region 为正式路径；自动文字检测从 V0.2 开始，不要求完整气泡检测。
- 支持手工框选作为所有自动能力的基础和兜底。
- 自动检测返回 Blocks、Lines、Mask 和置信度。
- 用户可以移动、缩放、删除、拆分或新增检测区域。
- 检测结果必须映射回源图像坐标。

气泡检测、分镜检测和拟声词专用检测属于后续增强。

### 4.3 OCR

- 支持对单个区域、当前页和批量页面执行 OCR。
- V0.1 接入一个 Manga OCR ONNX 实现；其他 OCR 引擎属于后续可替换能力。
- 支持横排、竖排和低质量扫描的结果校对；V0.1 不承诺完整振假名识别。
- 保留置信度和失败状态。
- OCR 结果可人工编辑，重新 OCR 前要保护或提示人工修改。

### 4.4 上下文翻译

- 按阅读顺序组合整页区域后翻译，避免逐句无上下文调用。
- 请求携带稳定 Region ID、语言、术语表和可选前页上下文。
- V0.1 使用 OpenAI-compatible Chat Completions 的非流式结构化响应，校验后按 ID 合并。
- 缺失 ID 只使对应区域失败；重复 ID 使整次响应失败；未知 ID 被忽略并提示响应异常。
- 支持单区域重译和风格指令。
- 支持多个候选译文。
- 区分模型输出和人工最终稿。
- 对付费调用提供明确进度、取消和不确定结果处理。
- V0.3 仍以单页为提交和输出单位；默认最多使用前 2 页确认文本、1,000 token 章节摘要和每个 Region 5 条 TM 候选。
- 当前页和强制术语不得裁剪；仍然超限时任务进入 blocked，不静默减少当前页内容。
- 上下文只能辅助当前页，不能返回或修改前页数据。

### 4.5 阅读顺序

- 项目设置支持左到右和右到左。
- V0.1 保存稳定 `orderIndex`，但不提供独立阅读顺序工具。
- V0.2 提供人工调整阅读顺序。
- V0.3 使用规则生成候选顺序并显示置信度；保存的 `orderIndex` 始终权威，混合横竖排页面不强制排序。
- 分镜、气泡语义模型和跨页阅读顺序推断不属于 V0.3。

### 4.6 原文清除

- V0.1 使用纯色/近似纯色背景填充。
- V0.2 使用 OpenCV Telea/Navier-Stokes 处理普通复杂背景。
- V0.3 使用固定漫画 LaMa ONNX 候选作为 CPU 高级选项；失败时保留 OpenCV 或人工结果并要求检查。
- Mask 可预览和人工修正。
- 清除结果不覆盖原图，允许恢复和重新生成。

### 4.7 自动排版

- 根据区域寻找最大可用字号。
- 支持横排/竖排、对齐、字重、行距和边距。
- 支持项目默认字体及区域级覆盖。
- 文本不得越出有效排版区域，溢出时给出明确提示。
- 用户修改译文后即时更新预览。
- V0.3 支持基础日文禁则、竖排标点、中英文混排、字体回退、缺字提示、项目预设和批量应用样式。
- 自动适配依次减少字号、调整行距、缩小边距，仍然失败则报告溢出；绝不自动改写译文。
- 后续支持气泡形状内排版、拟声词样式和更复杂字体效果。

### 4.8 导出

- 导出单页、选中页面或整个项目。
- 将原图、清除层、翻译层和人工覆盖层合成为最终图像。
- V0.1 输出 PNG/JPEG，不支持 WEBP 导出；后续支持重新打包 CBZ 和 PDF。
- 支持输出尺寸、质量、命名模板和目标目录。
- 采用暂存后提交，失败时不留下被误认为成功的半成品。

## 5. 状态、反馈和恢复

每个长任务提供：

- 等待、运行、暂停、完成、失败和取消状态。
- 可比较进度时显示确定进度；无法比较时显示活动状态。
- 当前页/阶段和简短状态说明。
- 失败原因、重试入口和安全诊断。
- 防止重复提交同一操作。

项目保存状态、后台任务和模型可用性在应用底部提供轻量反馈。持久问题使用 InfoBar；短暂成功提示使用 Toast。

## 6. 快捷键与可访问性

建议支持：

- `Ctrl+O` 打开，`Ctrl+S` 保存，`Ctrl+Shift+S` 另存。
- `Ctrl+Z`/`Ctrl+Y` Undo/Redo。
- `+`/`-` 缩放，适应页面和 100% 的快捷入口。
- Space 临时平移，Delete 删除选区，Escape 取消当前工具/操作。
- 主要页面可保留 `1`–`5` 快速切换，但不得覆盖文本输入。

所有图标按钮有可访问名称和 Tooltip；键盘焦点、默认按钮、对话框 Escape 和 IME 输入必须可用。

## 7. 版本规划

完整版本边界、完成标准、风险和维护规则以 [`docs/roadmap.md`](roadmap.md) 为准。以下内容保留为功能设计摘要；发生差异时应同步修正文档，不得形成两套路线图。

### V0.1：可用的人工辅助编辑器

- 图片/文件夹导入。
- 目录型项目创建、保存、备份恢复和重新打开。
- Pages + Canvas + Inspector 基础骨架。
- 手工框选和编辑轴对齐矩形 TextRegion；不支持旋转和多边形。
- OCR 接入一个 Manga OCR ONNX 实现，并允许人工录入原文。
- 翻译接入 OpenAI-compatible 非流式结构化响应。
- 手动或简单填白清除。
- 基础字体缩放与排版。
- Undo/Redo 和非破坏性图层。
- PNG/JPEG 导出，不支持 WEBP、CBZ 或 PDF 导出。

完成标准：不依赖自动文字检测，也能走通“导入—框选—OCR—翻译—排版—导出”。

### V0.2：自动文字检测

- ONNX Runtime CPU 与固定 1024×1024 comic-text-detector ONNX 候选模型。
- 自动生成 TextRegion、Lines 和自动/有效 Mask。
- 检测差异预览、字段级人工覆盖保护、选择和人工修正。
- 具有资源与路径安全限制的 CBZ/ZIP 导入。
- Qt PDF 300 DPI 导入及页面资源限制。
- OpenCV Telea 基础清除与人工阅读顺序调整。
- 可取消、可局部重试的页面级一键处理。

完成标准：用户导入页面后可自动看到文字框，并能修正后继续 OCR 和翻译。

### V0.3：整章智能工作流

- 使用可恢复页面阶段状态的整章任务，以及暂停、取消、重启恢复、stale 处理和失败重试。
- 有预算上限、固定裁剪顺序且不静默降级的单页输出/跨页上下文翻译。
- 完整全局/项目术语库和独立 Translation Memory。
- 规则式自动阅读顺序候选和人工采用。
- 固定漫画 LaMa ONNX 的 CPU 复杂背景修复及 OpenCV 回退。
- 基础日文禁则、竖排标点、混排、字体回退和联合尺寸适配。
- 候选译文、人工版本优先和集中问题校对。
- `Info`、`Caution`、`Error`、`Blocking` 分级；“已校对”只能由用户确认。

不包含 DirectML/CUDA、流式翻译、云后台、旋转/多边形 Region、完整振假名和复杂拟声词艺术字。

完成标准：可以批量处理整章，再通过编辑器完成集中人工校对和导出。

## 8. 非功能需求

- UI 在推理、网络、导入和导出期间保持响应。
- 关闭页面、项目或应用后，旧任务不得写回新状态。
- 大页面和大量 Region 使用有界缓存和惰性加载。
- Light/Dark、正常/窄宽度和高 DPI 下布局可用。
- 用户内容和密钥默认不写日志、不上传无关内容。
- 项目保存具备版本和故障恢复能力。
- 自动结果保留来源与状态，人工修改不会被后台结果静默覆盖。

## 9. 当前不作为首版目标

- 完全无人校对的一键成品承诺。
- 平台私有或加密漫画格式。
- 全功能 Photoshop 式图像编辑。
- 自研所有 Fluent 基础控件。
- 首版即实现精确气泡、分镜和拟声词检测。
- CBZ/PDF 导入、自动文字检测、Region 旋转或多边形编辑。
- 流式 LLM、复杂 Inpaint、完整日文禁则和振假名排版。
- 为每个文本区域创建重量级 QWidget。
- 将 AI 做成独立聊天窗口；AI 应作为当前区域和页面的上下文工具。

## 10. 产品验收主线

首个真正可验收的纵向切片是：

```text
打开一页漫画
  -> 手工创建文字区域
  -> 在 Inspector 编辑原文和译文
  -> 画布实时显示译文
  -> 保存项目
  -> 重新打开后状态一致
  -> 导出最终图片
```

在这条主线稳定后，再接入自动检测、OCR、LLM、清除和批处理。这样可以先验证最关键的数据模型、画布交互、非破坏性编辑和持久化设计。
